# 保种管家（`seed-hub`）

自动转种 + IYUU 自动辅种 + 保活守护：PT 保种最常见的三件事，一个插件全管。
三个引擎共享同一套「判重 → 路径换算 → 加种 → 校验编排 → 删源 → 报告」流程，
全部自动跑，周期在「设置 → 定时任务」里调。

## 三件事

### 转种（本地搬运）

把源下载器里已完成的种子搬到目标下载器继续做种——换下载器、换机器时用。

- **源侧读磁盘种子文件**：qB 的 `BT_backup`、TR 的 `torrents` 目录，都是 `<info_hash>.torrent`，
  任意版本的 qBittorrent / Transmission 都能当源（TR 没有 RPC 导出，只能这么读）。
  qB ≥ 4.5 时磁盘文件缺失再用 WebUI 导出兜底。
- **只转已下载完的**：直接问源下载器要「已完成」清单；还在下载、暂停没下完的一律不动。
- **目标直连加种**：指向已有数据、暂停加种 → 触发校验，后台 watcher 每分钟看进度、
  完成即恢复做种；目标 qB + 「跳过校验」时加完直接开始（数据不完整会坏档，想清楚再开）。
- **路径换算**：直接用内核里两台下载器已配的路径映射，不用重复填一遍；
  没配映射时视为两台视角一致。
- **判重与过滤**：目标已有同 hash 跳过；排除标签、最小体积过滤；
  源数据已不在原位（被整理/进回收站）的跳过。
- **转完收尾**：加种后持续盯目标——本地报错且重下就能恢复的空壳任务自动清掉；
  「分片损坏」这类删了就找不回来的只告警。超时不再干等。
- **删源（默认关）**：走内核 `dl.torrent.delete`，只删任务不删文件，过 H&R 保护、
  订阅状态正确联动；MovieClaw 投递的种默认跳过（删了订阅会重下）；
  「目标已有同种时顺手清源」也是默认关。
- **站点标签（MP 风格）**：按种子文件里的 tracker 域名补一条「站点/名字」，
  配合转种 / 辅种标签，一眼分清主种、辅种和来源站。

### 辅种（IYUU 跨站补种）

拿已完成的种子去 IYUU 匹配其他站点的同种，自动加回下载器——一个种子在多个站做种。

- 需要在设置里填 IYUU 令牌（iyuu.cn 用户中心）；站点目录免令牌。
- **取种链接三级策略**：IYUU 给的模板链接（`download.php?id=x`、`/dl/x/{passkey}`）在不少站
  直接 404，所以先按发布名在目标站搜索真实链接（id 精确命中优先，名称模糊命中次之）；
  搜不到再回填模板链接——回填用浏览/搜索时学到的站点凭据（passkey 等，加密存在插件数据里），
  让原本必死的兜底链接可用。
- 取种与投递经内核 `dl.submit` 带站点登录态完成，**插件碰不到站点 Cookie**。
- **沿用原种保存路径**（IYUU v2.18 口径）：原种在哪台下载器、什么目录，辅种就投到同一台的
  同名目录（经路径映射反向换算成 MovieClaw 视角）；拿不到再落兜底根目录。
- **成功缓存 + 台账**：辅过的不再重复提交；已在做种但台账没有的历史辅种自动补录；
  台账逐条可删（顺带从下载器移除该任务，不会再自动加回）。
- **站点冷却**：单站取种连续失败自动冷却（超时 1 小时、要求凭据/种子已删 24 小时）；
  每轮有提交上限与 10 分钟时间预算，不让一个慢站拖住整轮。
- **标签分得清**：辅种打「辅种」「MovieClaw」，转种打「转移做种」「MovieClaw」，
  主种是 `movieclaw-sub` / `movieclaw-manual` / `movieclaw-boost`，来源站另有一条「站点/xxx」。

### 保活守护（智能清理）

定期检查所有下载器，把「已经没意义」的种清出去，不让下载器变成垃圾桶。

- **站点已删种**：全部真实 tracker 都报 `not registered` / `torrent banned` 才判死。
  qB 排除 DHT/PeX/LSD 伪条目与「私有 torrent」提示行；有一个 tracker 活着就是活种。
- **数据丢失**：TR 本地错误 `No data found` 且校验未过；校验完好的不动（可能只是保存路径变了）。
- **分片损坏**：只告警，不自动删——重新校验多数能修，删了就找不回来。
- **主种空壳**：MovieClaw 主种的数据已不在原位时，先用内核删种预演判断，
  会被订阅重下（整季退回缺资源）的一律保留，只是空壳的才清掉。
- **永不碰**：MovieClaw 主种与保护标签（默认「留」「保留」）的种。
- **只删任务不删文件**；默认「只报告不删除」，先跑几轮看过报告再放开。

## 删片联动（自动停种）

媒体库里删片、或者清空回收站时，对应的下载任务立刻从下载器里移除，不用等守护下一轮。

- 监听 `library.file.deleted` / `library.file.purged`（可靠事件，按投递 id 幂等，
  同一件事来两次也只处理一次）。
- 按被删文件的 id 反查它来自哪个下载任务，三道安全线任一命中就保留：
  下载器配置已删除、这个种还供着库里别的文件、投递时有 H&R 考核风险；
  主种额外过一遍内核删种预演，会被订阅重下的也保留。
- 两个开关：**删片后自动停种**（默认开）；**停种时同时删数据文件**（默认关，
  只移除任务、数据留在硬盘上）。进回收站不触发，只有真正删除/彻底清除才动。

## 网页

左侧栏「保种管家」，一页三标签：

- **概览**：转种 / 辅种 / 守护三张卡（上次结果、下次时间、手动执行）、配置自检、
  最近报告；删片联动的开关状态也在这里。
- **待清理**：守护最近一次扫描的完整候选表格（可清/告警、原因），比报告里的明细全。
- **运行日志**：只显示本插件的关键事件，跨重启保留，可按级别过滤、可清空。

PC 端三张卡同一行、高度对齐；手机端自动重排成卡片。配色跟随 MovieClaw 主题。

## 命令与事件

接口会进入 mclaw 命令目录：

| 命令 | 用途 |
|---|---|
| `mclaw plugins seed-hub status` | 配置自检、上次报告、待做种队列 |
| `mclaw plugins seed-hub run --kind transfer\|reseed\|sweep [--dry-run]` | 手动跑一轮 |
| `mclaw plugins seed-hub transfer-scan` | 源里每个种子的转移结论 |
| `mclaw plugins seed-hub sweep-candidates` | 守护候选完整清单 |
| `mclaw plugins seed-hub logs [--level warning]` | 本插件日志 |
| `mclaw plugins seed-hub reseed-ledger` | 辅种台账（可逐条删） |
| `mclaw plugins seed-hub verify-check` | 立即检查转种后置校验队列 |

每轮跑完会发一个插件事件：`seed-hub.transfer.completed` / `seed-hub.reseed.completed` /
`seed-hub.sweep.completed`，Webhook 与别的插件都能订阅；另有两条通知模板（默认关），
想推到手机 / IM 去「设置 → 通知」打开。常驻任务连续失败会通过插件健康上报显示为异常，
恢复后自动转好。

## 设置要点

| 字段 | 说明 |
|---|---|
| 源 / 目标下载器 | 填「设置 → 下载器」里的名称或数字 id；两者不能是同一台 |
| 源种子文件目录 | 容器内挂载路径，每行一个；TR 做源必填 |
| WebUI 密码（源/目标） | 保险库凭据插件读不到，这里重填一次；加密存储、不回显 |
| 跳过校验（仅目标 qB） | 快，但数据不完整时坏档不会被发现；TR 无效（添加后自动校验） |
| 校验超时 | 加种后多久还没校验完就不再等；0 = 不超时 |
| 删源 / 删重 | 都默认关；走内核通道，只删任务不删文件 |
| 转种 / 辅种标签 | 默认「转移做种,MovieClaw」「辅种,MovieClaw」；站点标签另开 |
| IYUU 令牌 | 留空 = 不跑辅种；sid 留空 = 匹配全部已知站点（无本机映射的自动跳过） |
| 每轮最多提交 | 防止一次塞爆下载器；0 = 不限 |
| 只报告不删除 | 守护默认开；关掉才真删 |
| 删片后自动停种 / 同时删文件 | 前者默认开，后者默认关（只删任务不动数据） |

装好后先到插件设置里填好上面的目录与凭据，再到「定时任务」确认三个任务的状态即可。
首次安装批准路径时，把你填的源种子文件目录一并授予（只读）。

## 定时任务

| 任务 | 默认周期 |
|---|---|
| 自动转种 | 6 小时 |
| IYUU 自动辅种 | 24 小时 |
| 保活守护（智能清理） | 12 小时 |

配置不齐时自动跳过并记日志；手动执行进行中时定时轮自动让路。
订阅下载完成、入库完成也会触发一轮转种，不用干等定时。

## 权限与契约

- 宿主操作：`dl.list`、`dl.tasks`、`dl.submit`、`dl.file-sources.list`、`dl.torrent.delete`、
  `site.list`、`site.show`、`search.torrents`、`site.proxy.request`。
  其中 `dl.torrent.delete` 与 `site.proxy.request` 是破坏性 / 敏感操作：
  前者只在删源、删重开关打开或守护从「只报告」转正式、或删片联动命中时才调用，
  且只删任务不删文件（除非你显式打开「同时删数据文件」）；后者只借宿主登录态打开站点详情页，
  凭据不出宿主。
- 路径：源种子文件目录，只读。商店版不带默认路径，按你实际填的目录批准。
- 网络：`network = true`（IYUU 接口、qB/TR WebUI 直连），走 MovieClaw 的代理设置。
- 契约：`scheduled-tasks`、`plugin-files`、`download.completed`、`library.ingest.completed`、
  `library.file.deleted`、`library.file.purged`、`kernel/durable-events`、`plugin-events`、
  `plugin-health`。
- 站点凭据（passkey 等）加密存放在插件数据里，仅在回填 IYUU 模板链接时使用，
  界面里只显示打码后的形态。

## 与 `seed-scheduler` 的关系

`seed-scheduler` 管的是「做种多久之后删」（按时间清理）；本插件的守护管的是
「哪些种已经没意义」（按状态清理：站点删种、数据丢失、数据不在原位），两者口径不同，
同时安装也不冲突。
