# 映屿 v0.11.1 使用教程

## 从 MovieClaw 打开

MovieClaw Server 0.41.0 起正式提供插件网页导航。安装并批准本版后，管理员在「设置 → 插件 → 插件网页」检查映屿：同意网页运行，选择「加到侧边栏」；是否让普通成员看到由管理员决定。

网页以当前查看者身份运行，管理员打开时具有管理员的权限。这项同意必须由人在 MovieClaw 网页里确认，不能用代理或命令行凭据替代。每个插件包版本都要重新批准。网页授权与插件的 inline 主进程运行授权是两项不同的决定。

电脑从主导航打开「映屿」这一个入口；手机浏览器从「我的」找到「映屿」。进入后使用页内导航切换「海报墙、录像厅、平台热榜、随心看剧」。可在「设置 → 外观 → 导航顺序」调整或隐藏自己的入口。当前官方原生 App 不展示插件网页，请使用浏览器。

插件入口与四个页内板块地址使用当前服务器地址，局域网与公网都无需另填链接。同一服务器同一账号使用同一份推荐偏好；不同域名仍需各自登录。

| 页面 | 相对服务器的原生地址 | 用途 |
| --- | --- | --- |
| 海报墙 | `/apps/platform-discovery/` | 根据口味、喜欢与片单探索影片 |
| 录像厅 | `/apps/platform-discovery/theater` | 筛选媒体库库存并进入 MovieClaw 播放 |
| 平台热榜 | `/apps/platform-discovery/platforms` | 查看平台片单及其来源与统计时间 |
| 随心看剧 | `/apps/platform-discovery/random` | 按地区随机探索新旧剧集 |

切换板块会更新地址；刷新、收藏、分享同源地址及前进／后退可回到对应板块。电脑和手机均使用页内四项切换条，手机简化为短标题；主程序不会再展开成四个入口。入口是否显示由宿主授权和个人导航偏好决定。

## 海报墙与账号偏好

可反复进行口味测试，保留本次及往期偏好。海报上的快捷操作支持喜欢、已看过、稍后看和不感兴趣；已看过默认排除。国家、年代和题材可多选，也可排除题材、调整探索程度、收藏筛选方案。浏览历史及近期操作撤销位于「更多设置」。

打开影片详情可看简介、参演资料并放大海报。订阅需先预检，剧集可选季，明确确认后才创建，不会因浏览或预加载自动订阅。权限和订阅策略沿用宿主。

## 全屏与屏保节奏

点「全屏海报墙」优先请求浏览器原生全屏。海报按实际可视区域排成完整行列，保持比例；纵深呼吸不沿屏幕上下移动。

静置五秒后开始随机位置轮替，操作或打开对话框暂停后续更替，关闭后重新冷却。预载最多三面，预载不计已展示。新图尚未准备好时保留旧图。原生全屏不获允许时铺满正文区域，工具栏提供「独立打开屏保」，在独立页面铺满浏览器可视区；浏览器自身的地址栏是否隐藏由浏览器决定。

「屏保节奏」可从全屏工具栏或「更多设置」进入：

| 设置 | 范围 | 默认 |
| --- | --- | --- |
| 淡出 | 0.6–6 秒 | 2.0 秒 |
| 淡入 | 0.6–6 秒 | 2.6 秒 |
| 海报更替间隔 | 0.2–5 秒 | 0.8 秒 |
| 画面交叠 | 0–80% | 60% |
| 节奏变化 | 0–45% | 25% |

较大的交叠让旧图还未消失时新图开始浮现；较小的间隔让多张海报错落交接。变化幅度控制时长和间隔在基准附近的随机变化；归零就是固定节奏。最多六张同时变化，避免长动画无限叠加。恢复默认先恢复草稿，仍需点「保存节奏」。节奏跟随账号，下次打开全屏或设置面板时读取另一设备保存的值。

## 录像厅与播放返回

录像厅只显示当前账号有权访问的媒体库。可切电影／电视剧、媒体库、合集，或在分类筛选中继续缩小范围。海报可按作品身份从 TMDB／可选 Fanart.tv 选优并缓存到服务器；可手动挑选、锁定海报，缓存受容量上限控制。

进入库存详情后，电影点播放，电视剧选择季与集。播放和「主程序库存详情」会在主程序打开，不在插件里再嵌一层 MovieClaw。插件记录录像厅返回地址与当前账号的筛选位置，播放器仍由宿主控制。

## 找不到入口或登录过期

1. 确认服务器为 0.41.0 或更新版本，插件正在运行，且未开启安全模式。
2. 管理员检查该插件本版本的网页同意及「加到侧边栏」。普通成员还需「成员也能看到」。
3. 检查个人「导航顺序」里是否已隐藏入口。
4. 登录过期时，登录后回到原板块。只接受本服务器内已知插件路径，不使用任意外部回跳地址。
5. 旧版服务器或独立打开时，仍可使用 `/api/v1/plugins/platform-discovery/panel?view=personal`；将 `personal` 换成 `theater`、`platforms`、`random` 可打开其他板块。

第三方接口、图床及冷缓存速度取决于服务器网络。插件不会修改宿主的代理、TMDB 接口或图片镜像；如显示来源连接失败，先检查已有网络设置与来源状态。

## 更新与回退

更新插件前备份当前版本完整一致的数据目录（数据库、密钥、插件设置和加密账号数据），同时保留当前插件包、版本和授权记录。不要重建账号或删除插件数据来排查菜单问题。

本次插件适配不迁移宿主数据库。需要回退时安装此前保留的插件包并按宿主流程重新批准；这不会自动恢复被手工删除的数据。主程序 0.40 → 0.41 的数据库回退是另一件事，必须使用与该宿主版本匹配的一致备份，恢复升级前备份会丢失此后新增的数据。

## 开发维护

`platform_discovery/assets/page.html` 是页面唯一源文件。修改后运行 `python3 tools/build_web.py` 更新 `web/index.html`；`python3 tools/build_web.py --check` 检查同步。原生页直接加载同源插件资源，只有宿主提供的一层 iframe。不要重新加入嵌套包装页。

菜单使用 W3C Web App Manifest 的 `shortcuts`。保持现有三项顺序稳定，新增入口追加到末尾，避免改变宿主个人导航中既有项的身份。图标为随宿主文字颜色变化的单色 SVG。

## 从平台放映厅更新到映屿

直接更新同一个 `platform-discovery` 插件。改名只影响显示名称及导航组织，保留全部账号档案、设置和服务器海报缓存；旧版四个板块的收藏链接仍可打开。不要卸载、清理数据或更换插件 ID。
