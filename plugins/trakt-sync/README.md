# Trakt 自动追踪

[English](README.en.md)

把 MovieClaw 上报的电影、单集播放活动同步到各成员自己的 Trakt 账号。

> 默认使用 MovieClaw 项目账号维护的 Trakt 公开应用。无需申请 Client ID 或填写 Client Secret；连接时登录你自己的 Trakt 账号并批准授权。

## 安装与更新

用管理员账号进入 **设置 → 插件 → 插件市场**，搜索「Trakt 自动追踪」，查看网络、播放事件及媒体库元数据只读权限并批准安装。更新同样从插件市场选择版本并批准；同 ID 更新保留账号与插件数据，不要求重启服务器。

安装后在网页侧边栏打开 **Trakt**，选择成员、点击连接，按 Trakt 的设备授权提示登录该成员自己的账号。管理员 ID 为 `0`；每位成员单独绑定，未连接的成员不会使用管理员的授权。管理员可在高级设置里填写其他成员 ID；本版本不提供普通成员自助管理。

**删除 MovieClaw 成员前，先在本插件中断开他的 Trakt。** 成员 ID 可能被复用；插件当前没有成员删除通知可自动处理这件事。

Trakt 免费账号目前可连接 2 款第三方应用，官方 Trakt 应用不占名额。本插件占一个名额；具体以 [Trakt 当前政策](https://github.com/trakt/trakt-api/discussions/943) 为准。不要为测试随意撤销已有授权，重新授权可能受限。

## 功能与边界

- 联网开始或恢复播放时上报正在观看，结束及完成时按 Trakt 规则记录观看。
- 按 TMDB / IMDb 编号和季集编号匹配，不按标题猜测；支持电影和电视剧单集。
- 每个成员独立保存加密授权、队列及同步活动；页面可看失败原因、重试匹配失败的记录。
- 只同步向 MovieClaw 上报播放活动的客户端。独立通过 Plex 播放的 Infuse 不经过本插件。
- 不同步手动标记已看、取消已看、收藏、评分，不导入已有历史，也不把 Trakt 的进度反向写回 MovieClaw。

已针对 MovieClaw v0.42.0 验证契约、入口、隔离宿主集成与自动回归。

**离线补报有限制：** 插件只能处理宿主实际发送的事件，无法补出没收到的重看或历史完成记录。当前不承诺按每次离线观看区分完整历史，也不承诺 `viewing_id` 可用。App 需要再次运行并连上 MovieClaw；真实 iPhone 飞行模式到恢复联网的完整链路仍待验收。只收到当前已看状态，不能推断所有过去观看次数。

## 正式版与开发版

`main` 和插件市场使用正式版 `0.2.3`。`dev` 的 `0.3.0-beta.1` 包含依赖尚未合并服务器接口的开发功能，不能代替正式版，也不会自动进入市场。

## 失败记录恢复

新记录保留本地媒体/文件 ID。媒体库纠正外部编号或季集后，重试会按文件 ID 读取当前元数据，按原观看时间核对 Trakt，缺失才补传。若本地条目或文件记录已删除，则停止此条任务；文件暂时缺失则继续等待。此操作不会删除 Trakt 历史，也不读写视频文件。

旧版记录可能没有本地文件 ID，无法自动推断原文件。电视剧可展开失败详情，填写正确季号、集号，点击「修正季集并核对」；无法确认或不再需要的记录可「忽略此记录」。开始/进度/未完成停止超过 5 分钟后不补传，不会伪造一次已看。

账号面板显示的是当前保留的失败数量，不是累计失败总数。同步活动是有限的近期记录。

## 同步出问题时

| 情况 | 行为与处理 |
| --- | --- |
| 网络或 Trakt 暂时故障 | 按 Retry-After / 退避重试；未发送队列最多 64 项、60 KB |
| 队列容量不足 | 先清理过期实时任务与心跳；仍不足则舍弃旧任务，在账号面板提示未同步数量，不阻塞其他成员；可确认清除提示，累计数量保留，不会补发 |
| 授权失效 | 停止此成员的新任务，清除旧待发队列并提示断开后重新连接；不自动补回这些记录 |
| 单条请求无效（400）或影片匹配失败（404/422） | 保留失败记录，10 分钟至 6 小时退避自动核对；重新读取本地元数据、核对 Trakt 历史后补传，不阻塞后续影片 |
| 断开连接 | 清除此成员的本地授权、队列，尝试撤销远端授权；未确认时前往 Trakt 已连接应用处理，不删除观看历史 |

**保留旧应用绑定：** 更新前在高级设置中显式保存原应用 Client ID，即可继续使用原绑定。只有主动换到新的默认应用时，才需要先断开旧连接并重新授权；切换应用不会删除 Trakt 历史。撤销授权可能延迟生效，本地断开立即停止发送。

同步活动不展示开始/进度心跳，避免挤掉观看与失败记录。近期展示记录不是永久历史档案，也不保证无限离线积累或绝对不重复。
