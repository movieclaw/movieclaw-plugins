# 0.2.3 发布前验证

本版只修复插件 PR #3 的 P2 容量边界问题，不包含 dev 分支功能，不改宿主。

- 先用旧实现运行新增回归：两条完成记录场景会发生未受跟踪的远端写入、下一条被误删；单条场景会在写入后抛出 IndexError。两项测试失败，确认问题可复现。
- 修复后仅发送容量整理后仍在持久队列中的完成任务；按任务 ID 移除，避免误删队首之外的其他记录。正常容量淘汰仍计入丢弃提示，不声称无限保留。
- 三项新增回归覆盖：两条任务时后续完成记录不被静默删除；单条任务淘汰后不进行无持久记录的远端写入；淘汰心跳时完成任务保持 uncertain 状态落盘，模拟远端成功/进程退出后重启查重、不重复写入。
- 源码完整测试 147 项及 13 个子测试通过；市场相同 unittest 入口 51 项通过。Ruff、JS 语法、空白检查、打包及固定 MovieClaw v0.42.0 契约/操作权限检查通过。
- 自动测试中的 Trakt HTTP 为模拟响应；包含固定宿主 SDK 的实际插件生命周期与管理路由集成。本版不为边界测试制造生产观看记录或填满生产队列。

发布条件：当前 PR head 的独立 GitHub Codex Review 完成且没有待处理发现，并且 CI 通过，才允许合并与发布。线上升级及市场提交结果以 Release 和 PR 后续记录为准。
