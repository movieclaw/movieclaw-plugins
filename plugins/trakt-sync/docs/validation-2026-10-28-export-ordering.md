# 导出与取消已看顺序保护（2026-10-28 UTC）

本轮修复 [PR #1 的 P2](https://github.com/o1xhack/movieclaw-trakt/pull/1#discussion_r4395842024)：导出 12:35 的观看之后，晚到的 12:34 取消事件可能删除较新的远端观看。此前导出只保存来源／分钟回执，没有加入 Engine 的观看顺序保护。

## 修改

- 导出确认成功或已核对远端存在时，先保存成员／绑定／电影或单集范围的观看标记，再提交来源和指纹成功回执；失败后恢复不会因已有回执漏掉这个步骤。
- 旧指纹回执以及来源别名回执读取时补齐观看标记。别名目录后来变成 12:45，仍用最初导出回执中的精确源时间，不冒用新的目录时间保护较旧观看。
- 原生完成事件恢复不确定导出时，也保留该导出实际源时间的顺序保护，覆盖尚未恢复前台历史任务的间隔。
- 没有按 Trakt 分钟归零处理本地顺序。源时间前后 1 微秒的取消分别验证：较旧取消跳过，较新取消正常发送。
