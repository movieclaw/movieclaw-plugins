# 123 云盘

## 1.0.0

- 发布 1.0.0 正式版本，保留 0.1.0-beta.10 的现有功能、依赖锁和权限。
- 加入 123 云盘官网图标，保留原始像素及透明度，并记录图片来源。

## 0.1.0-beta.10

- 分片 PUT 改为 64 KiB 分块发送，保留准确 Content-Length 和单次请求，避免整片作为一次传输写入而在慢连接上超时。
- PUT 响应读取超时从 20 秒调整为 60 秒，连接、写入及连接池超时不变；不增加重试或改变分片对账与恢复语义。
- 增加白名单 PUT 错误诊断和流式请求、取消、慢写、停滞及延迟响应回归；不记录 URL、凭据或原始异常。
- 精简使用说明和历史更新说明，保留功能、行为边界及通用验证方式。依赖锁不变。

## 0.1.0-beta.9

- 回收请求 `fileTrashInfoList[].FileId` 改为 JSON 整数；SDK 和详情查询仍用字符串 ID。
- 保留其他请求字段、宿主出口及逐文件回收核验，补充整数 ID、大整数精度和部分成功回归。

## 0.1.0-beta.8

- 补充回收响应 `InfoList` 的受控摘要，覆盖字段存在性、类型、条数、目标匹配及回收状态。
- 不改变请求、成功判定或重试规则；补充异常结构、重复及无关项的回归。

## 0.1.0-beta.7

- 增加回收调用内脱敏日志，保留请求、逐文件核验及取消规则，不增加请求或自动重试。
- 覆盖诊断脱敏、预算拒绝、并发隔离、取消、关闭与日志写入失败。

## 0.1.0-beta.6

- 回收请求保留 `driveId`、`fileTrashInfoList` 大小写，绕过依赖的字段小写转换。
- 保留账号及文件预查、回收后逐项核验和失败保护。

## 0.1.0-beta.5

- 提供扫码与 Token 登录、账号容量、目录遍历与创建、文件详情、原文件直链和回收站删除。
- 支持 MD5 秒传、服务端分片布局、多分片对账和持久化恢复；普通上传校验分片 ETag、合并确认及成品绑定，秒传和证据不足时回读全文 MD5。
- 合并结果未知时先对账并保留未解决会话，保留取消、异常及清理重入保护。
- 去掉早期内部版本的文件总大小、两片及固定整会话容量限制；实际规模仍受宿主和账号能力约束。
- 补齐元数据、许可证与使用说明，依赖固定版本和哈希。
