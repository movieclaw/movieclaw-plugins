- 内部包的 373 项离线测试（含删除 38 项、加载注册 9 项）及清单、依赖锁检查通过；依赖锁不变。此次同步仅复核已有证据，未新增真实网盘操作。

- 补充回收响应 `InfoList` 的脱敏摘要：存在性、类型、条数、逐项目标匹配及 Type/Trashed；不输出原始行、真实 ID 或凭据，不改变删除和核验逻辑。

## 0.1.0-beta.7

- 内部诊断包：保持 beta.6 删除请求及核验流程，仅增加 `123-delete-diag` 脱敏日志，不增加请求、自动重试或等待。
- 记录请求字段名、ID 类型、HTTP 状态、业务码、受控响应结构及前后回收状态；用临时操作编号和文件序号关联，不记录真实 ID、凭据、文件名或原始响应。
- 新增 8 项离线回归，覆盖脱敏、异常响应、预算拒绝、并发隔离、取消与关闭失败、日志写入失败；删除相关 32 项通过。
- beta.6 在 v0.45.0 的用户实测仍失败，已有日志仅显示 HTTP 200。本包用于补足证据，不宣称删除故障已修复；待安装后单文件验收。依赖锁不变。

## 0.1.0-beta.5

- 提供扫码与 Token 登录、账号容量、目录选择与完整树列举、逐级创建目录、文件详情与原文件直链；删除移入回收站。
- 支持 MD5 秒传、服务端分片布局、多分片对账和持久化恢复；普通上传校验分片 ETag、合并确认及成品绑定，秒传和证据不足时回读全文 MD5。
- 合并结果未知时只读回查并保留未解决会话；保留取消、异常和清理重入保护。
- 去掉早期内部版本的 32 MiB、最多两片及固定整会话容量限制，移除额外的目录数量和记录预算限制。
- 按官方插件仓库补齐元数据、许可证与使用说明；依赖继续固定版本和哈希。
- 测试边界：离线覆盖多分片及恢复；本版本真实宿主已验证容量刷新和单集秒传闭环，普通大文件与中断续传仍待真实验收。
