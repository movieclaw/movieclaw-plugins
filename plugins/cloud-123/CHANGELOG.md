# 123 云盘

## 0.1.0-beta.5

- 提供扫码与 Token 登录、账号容量、目录选择与完整树列举、逐级创建目录、文件详情与原文件直链；删除移入回收站。
- 支持 MD5 秒传、服务端分片布局、多分片对账和持久化恢复；普通上传校验分片 ETag、合并确认及成品绑定，秒传和证据不足时回读全文 MD5。
- 合并结果未知时只读回查并保留未解决会话；保留取消、异常和清理重入保护。
- 去掉早期内部版本的 32 MiB、最多两片及固定整会话容量限制，移除额外的目录数量和记录预算限制。
- 按官方插件仓库补齐元数据、许可证与使用说明；依赖继续固定版本和哈希。
- 测试边界：离线覆盖多分片及恢复；本版本真实宿主已验证容量刷新和单集秒传闭环，普通大文件与中断续传仍待真实验收。
