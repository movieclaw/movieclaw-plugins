# 上传协议手动采样

`probe_upload.py` 用于分阶段收集上传协议响应，独立于 `cloud_123/` 的正式上传实现；不自行判定服务端完成状态、全文 MD5 来源或安全续传规则。测试中的响应均为合成数据，不是已验证的服务端样本。

使用已有 Python 3.12、固定 `p123client==0.0.9.4` 和 httpx，不新增依赖。脚本独立运行，不加载宿主，不执行 SDK 预算或 PLUGIN_DATA；因此不能替代插件集成测试。文件锁使用 POSIX `fcntl`，适用于 macOS/Linux 环境。

## 本地网页面板

可用 `probe_panel.py` 代替逐条输入采样命令；仅使用标准库提供本机网页，不新增依赖。用同一 Python 环境在插件目录运行：

```sh
python tools/probe_panel.py --workdir /绝对路径/已有采样目录
```

省略 `--workdir` 可从空面板新建；启动时自动打开浏览器，`--no-open` 可只打印地址。只监听 `127.0.0.1`，随机空闲端口；不要通过代理、隧道或端口转发公开服务。

- 打开或刷新面板仅读取本地状态及脱敏报告，不请求网盘。输入一次 Token 并点击“使用 Token”，密码框随即清空，后续阶段复用进程内 Token；不使用浏览器存储、不将 Token 写入文件或返回 API。点击“清除”或退出服务后移除持有的 Token。关闭网页本身不会退出服务或清除内存。
- 打开已有采样只需填本地目录。新建时填非根空网盘目录 ID，选择 12 MiB、32 MiB 或零字节；可勾选复用当前采样字节以验证秒传。新本地目录由工具生成，旧会话原样保留。
- “新建并初始化”“查询远端”“上传下一片”“提交合并”各执行一个阶段，没有自动推进或重试。所有远端阶段复用 `probe_upload.run`、真实 UID 核验、文件锁、写前意图和关闭保护。只有下一片可上传、全部片确认后才可合并；结果未知、已提交合并或会话字段无效时拒绝写操作。
- 面板串行处理操作；旧页面或重复提交的阶段票据被拒绝。刷新只读本地状态，不重放请求。关闭浏览器或请求响应丢失不会撤销正在执行的远端操作；重新打开后先刷新核对。终端 Ctrl+C 结束服务时会等待已开始的请求处理结束，不强行清除 pending。
- 页面及 API 校验 Host、Origin 和随机页面凭据，不开放 CORS；禁用缓存、外部资源和嵌入。适用于当前单用户本机采样，不作为公网服务或多用户应用。
- 页面展示和“导出报告”仅取 `samples.jsonl` 中的采样操作，**排除整个 identity 记录**，因此已有报告里的 Passport 等账号信息不会进入页面或导出。导出名为 `samples-review.jsonl`；不读取私有证据文件、不修改原报告，未知字段仍需共享前人工检查。
- 本地状态损坏不会自动初始化新会话；报告损坏或超过 4 MiB 时明确提示并禁用写操作，不截断证据或导出部分报告。

## 数据与副作用

- 只在用户指定的**非根目录、完全为空的独立测试目录**创建随机命名的 `.bin` 文件。默认生成 12 MiB 随机内容，最多 32 MiB（仅限此采样工具，不是插件上传上限）；`--bytes 0` 可采集零字节路径。
- 每个命令提示输入 Token，不回显、不作为命令行参数、不写文件。若 `getpass` 无法关闭回显，立即停止，不退回普通输入、不读取 Token、不发网络请求；须改用支持隐藏输入的终端。各阶段先查真实 UID，切换账号时拒绝继续。
- `start` 初始化；`put` 每次仅上传下一片；`complete` 仅在本工具已发送全部片后合并一次；`inspect` 仅查询文件详情与分片列表。没有自动重试、自动轮询、覆盖或删除操作。
- 写操作前保存本地意图。超时、取消、失败或保存响应失败后只允许 `inspect`；不要手动清除 `pending` 来重发，不把本工具当作生产续传实现。失败的地址申请也保守停止该会话。
- 本地目录为 0700，状态和样本为 0600。`private.json` 包含上传会话秘密，**不得共享或提交**；`sample.bin` 是采样字节。`evidence.private.jsonl` 保留 JSON 响应的协议原值，包括字符串状态、分页标记和完整 ETag（不要求它是 MD5）；它可能包含账号信息、文件标识和会话字段，**仅在本地分析，不得整份共享或提交**。
- 私有证据先移除已知鉴权字段、当前输入 Token、Bearer 文本和 HTTP(S) URL，再生成进一步脱敏的 `samples.jsonl`。两份使用相同时间及操作名对应；可分享报告仍对字符串等做代号处理，不再承担唯一证据的职责。不会记录请求鉴权头；未知字段及对象键仍需人工复查，不能把这套过滤当成任意响应都可公开的保证。非 JSON 响应仍只记字节数，不据此推断协议。
- HTTP 关闭失败不覆盖原始业务/网络异常或取消。只有关闭失败时给出脱敏错误；关闭期间的新取消继续传播。证据或报告写入失败也会中止当前阶段，保留写前意图，不因记录失败自动重发远端请求。
- PUT 不携带 API Bearer 或 API Cookie，所有请求禁止自动重定向。脚本直连、不读取环境代理配置；不冒充已验证宿主网络出口。
- 不自动清理网盘测试文件或未完成会话。完成采样后由用户在测试目录内检查处理。

## 分阶段执行

在插件目录内运行，`python` 指向上述虚拟环境。下面的 `TEST_DIR_ID` 必须替换成独立空测试目录的真实 id；采样目录选在仓库外，且 start 时不能已存在。

```sh
python tools/probe_upload.py start --workdir /tmp/movieclaw-123-probe-1 --parent TEST_DIR_ID
python tools/probe_upload.py inspect --workdir /tmp/movieclaw-123-probe-1
python tools/probe_upload.py put --workdir /tmp/movieclaw-123-probe-1
python tools/probe_upload.py inspect --workdir /tmp/movieclaw-123-probe-1
```

每条命令都重新启动进程。先保留“刚初始化”及“第一片后”的样本，再按响应中 SliceSize 对应的片数手动重复 `put` / `inspect`。如果 12 MiB 只产生一片，此轮无法证明多片恢复；可以在**新的空测试目录和新本地目录**用 `--bytes 33554432` 采样。仍然只有一片时如实记录，不能声称 R3 已通过。

全部片发送后，先 `inspect` 保存“全部片、未合并”样本，再执行：

```sh
python tools/probe_upload.py complete --workdir /tmp/movieclaw-123-probe-1
python tools/probe_upload.py inspect --workdir /tmp/movieclaw-123-probe-1
```

稍后可再次手动 `inspect`，比较完成后的状态变化。合并响应成功也不代表已取得成品正面证据。若未捕获处理中状态，这项验证仍然缺失。

验证秒传时可在另一个空测试目录，用新的本地目录和相同样本字节重新初始化：

```sh
python tools/probe_upload.py start --workdir /tmp/movieclaw-123-probe-2 --parent ANOTHER_TEST_DIR_ID --source /tmp/movieclaw-123-probe-1/sample.bin
python tools/probe_upload.py inspect --workdir /tmp/movieclaw-123-probe-2
```

`Reuse=True` 时脚本拒绝 PUT。初始化保存顶层 `FileId`，也兼容已有采样中的 `Info.FileId`；仅在 `Info` 实际含有 `FileId` 键时保存该字段，不为缺失键补 null。两处同时存在时必须都是有效正整数，规范化后相同，否则在 PUT/合并前拒绝。显式 null 或非法值不能靠另一处静默兜底；两处均缺失也拒绝。`SliceSize / Bucket / Key / StorageNode / UploadId` 仍按固定字段读取；未知形状保留证据并停止依赖它的动作。这些是查询/请求所需字段，不是完成状态映射，不要为“跑通”而猜测替代。

## 样本能够回答什么

比较初始化、部分上传、全部片未合并、合并后及秒传时的详情和分片列表，找出：哪些字段只是预分配回显、哪些字段能区分完成、分片编号/大小/确认值及列表是否有分页。样本同时记录本地预期大小和 MD5，可与成品 Etag 对照。

需要具体字符串或确认值时，在本地查看 `evidence.private.jsonl`，再人工选取并检查必要字段。早期版本仅有 `samples.jsonl` 时，已经摘要化的值无法恢复，需重新采样；私有证据文件不会反向重建旧响应。

17 项工具模拟测试覆盖手动阶段、顶层/嵌套文件 id、保存及重建后缺失键与显式非法值的区分、矛盾 id 拒绝、禁止回显降级、关闭异常与取消、私有证据/脱敏报告、结果未知及写记录失败后的禁止重发。它们不构成真实协议证据。

本工具不解析未知的分片分页，不判断应跳过哪些片，不重复 PUT/合并，也不故意破坏或删除远端对象。分页完整性、未知片安全覆盖、会话 TTL、同名成品复用和成品哈希来源仍需结合采样结果追加有针对性的验证；不能用几个字段相等宣称上传与续传已完整验收。插件当前能力及验收边界见 [README](../README.md)。

9 项网页面板离线测试覆盖本地打开与脱敏导出、Token 内存边界、阶段准入、过期请求、模拟 PUT/合并、超时及取消、失败会话保留、损坏状态恢复，以及本地 HTTP 来源和并发保护。网页人工检查使用合成 Token 和会话，不连接真实网盘。
