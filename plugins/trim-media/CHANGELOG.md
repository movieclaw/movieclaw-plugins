# 更新记录

## 0.2.0

**一页管理界面**（左侧栏「飞牛」，网页 `/apps/trim-media`）：

- **媒体库映射**：已接入的库（条目 / 文件 / 缺片统计、已写回片头片尾的季数）、
  飞牛上全部库（能否接入、为什么跳过）、一键接入、立即同步、**范围覆盖检查**
  （本机目录下有多少视频文件、MC 台账收了哪些、漏在哪些子目录）；
- **片头片尾**：MC 识别值 × 飞牛当前值按季对比，状态分「一致 / 不一致 /
  未设置 / 仅飞牛有」，可单季推送、全部推送、手工改秒数、清除；
- **飞牛账号与库权限**：当前登录账号、账号列表、每个账号可见哪些库（需管理员账号），
  改完立刻回读校验；
- **运行日志**：插件自己的运行记录，每 3 秒增量刷新；
- **差异检查**：飞牛里有哪些条目 MC 库里没有、反过来的也列出来（只读）。

**修掉的实质问题**：

- 片头片尾写回改成写**季的 guid**：飞牛按季存配置，写剧的 guid 不会生效；
- 路径映射的前缀按目录边界匹配：`/mnt/media` 不再把 `/mnt/media2` 算进去
  （原来会把整库路径算错）；
- 片头片尾总览与写回共用同一套「按季取中位数」口径，不再各算一遍。

## 0.1.0

第一个公开版本。

- **库接入**：发现飞牛影视的媒体库，把本机可见目录的库建成本地媒体库
  （`library.create`）——识别、刮削、海报墙、详情、播放、Jellyfin 全部走 MovieClaw
  主线，飞牛挂了照常播；按飞牛库 GUID 记账，**只加不删**；
- **观看进度双向同步**：MovieClaw → 飞牛走播放事件（20 秒节流，停止/看完不节流）；
  飞牛 → MovieClaw 定时拉「继续观看」并写回 `playback.sync.state`（带 compare-and-set），
  有播放活动时自动加速轮询；两侧靠 (TMDB, 季, 集) 收敛，共同有的片才同步；
- **片头片尾写回**：MovieClaw 识别完一季，按季取中位数写进飞牛的
  `skip_opening` / `skip_ending`（飞牛按季存、整季生效），值没变不调接口；
- 一个飞牛账号对应一个 MovieClaw 成员，避免把全家人的进度写进同一个账号。
