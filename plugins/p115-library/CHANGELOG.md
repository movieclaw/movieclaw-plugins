# 更新日志

## 2.8.3

- 修复：极速扫描时目录查询失败（如 115 风控返回 HTTP 405、网络异常）被误判为「目录已删除」，开启清理时会删掉该目录已生成的 STRM；现在本轮只跳过该目录且不做清理。
- 修复：逐目录扫描的断点在同步完整跑完后仍保留，导致下次全量几乎跳过所有目录，开启清理时还会误删它们的 STRM；现在断点只用于续传中断的同步，完整跑完后自动清除，续传那一轮也不做清理。
- 115 风控常见的 HTTP 405 改为等待冷却后自动重试，与 429/5xx 一致。
- 控制台同步状态区的错误信息、限速原因等文字改为转义显示，不再按 HTML 解析。

## 2.8.2

- 将使用说明加入网页控制台，提供五步配置流程、页面跳转和常见问题。
- 首次安装且未配置同步目录时，默认显示使用说明；支持 `#guide` 直达。
- 全量同步页增加完整使用说明入口，明确必须先新建媒体库并指定 STRM 目录。
- 保留 115 扫码登录、全量与增量同步、断点恢复、附属文件同步及后续剧集直链预取功能。

本版源码来自 `p115-library-2.8.2-movieclaw-v0.35.0.mcplugin`，原始目标宿主为 MovieClaw v0.35.0。详细历史与原包验证记录见 README.md 和 VERIFICATION.md。
