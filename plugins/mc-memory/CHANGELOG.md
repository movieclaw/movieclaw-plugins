# 更新记录

## 0.4.7

首个在本仓库发布的版本（此前为个人开发版，能力到此已定型）。

- **记忆 + 压缩二合一**：同一轮只读一次会话轨迹，同时驱动上下文自动压缩与长期记忆提炼。
- **记忆库**：五类笔记（iron / user / feedback / project / reference）、有界索引（软硬双上限、写前查重拦截）、按 id 取全文、关键词全文检索、`[[笔记名]]` 互链、体检（近似重复 / 超大笔记 / 失效链接 / 冷记忆）、归档与恢复（归档只移出索引，内容保留）。
- **上下文压缩**：消息数或输入 token 达到阈值自动压缩，带冷却与「运行中会话跳过」；只压不删，完整轨迹保留；提供压缩历史看板、累计节省 token 统计与手动压缩。
- **续接同步**：检测到新压缩摘要时先提炼一次，接住交接摘要里的进行中任务。
- **多后端故障切换**：最多三个 OpenAI 兼容后端按槽位顺序组成「主力→兜底」链，额度用尽 / 鉴权失效自动切换，瞬时抖动只重试。
- **管理页**：记忆管家整页——索引与卡片视图、检索、增删改、置顶、归档恢复、体检、压缩看板；操作按钮带图标。
- **AI 提炼引导**：自动提炼单条 ≤600 字、单次最多 8 条、宁低勿高，写入前查重；人工写入不限字数（2 万字兜底）。
