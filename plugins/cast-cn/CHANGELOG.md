# 演职人员中文刮削

## 0.3.4 - 2026-10-31

- 新增**失效头像修复**：老工具写进 NFO 的头像地址缺扩展名（TMDB 图床一律 404，详情页显示空头像），现在按 TMDB 人物 id 从人物表回填正确地址（人物页用的就是它，本地缓存多半还在），重写 NFO 并刷新；豆瓣未命中也能修，处理条件不命中的演员照修。
- 「保留现有头像」策略把失效地址按缺失处理：豆瓣照常能补。
- 「不改动头像」策略下不做修复（尊重用户选择）。
- 修复过程中若人物表也没有该人物，回退豆瓣匹配；都没有则保持原样等下一轮。

## 0.3.3 - 2026-10-31

- 换新图标：演员资料卡 + 人形 + 「中」字，直白表达「给演职员补中文」；侧边栏小尺寸下依然可读。

## 0.3.2 - 2026-10-31

- 全库补跑改为**批次窗口**：每批只排队 batch_size 条（默认 6），整批处理完并从活动中心消失后才排下一批——活动中心不再被几百个排队任务刷屏。
- 新增「每批并发显示」设置（1–50，默认 6）；补跑任务自带进度（已处理 X / 总量）和批次等待提示。
- 批内失败的任务自动忽略（记录都在插件报告里）；补跑被取消时连带取消批内任务；单批等待上限 45 分钟防卡死。

## 0.3.1 - 2026-10-31

- 修复复核失败的死循环：保鲜刷新的指纹守卫会跳过 NFO 重吸收（角色翻回英文），此前重试只重新刷新、不重写 NFO，注定再失败；现在复核失败后清除待刷新标记，让重试走完整流程（重新合并 + 重写 NFO + 再刷新），重写必然打破指纹守卫。

## 0.3.0 - 2026-10-31

- 新增「删除无头像的演员」开关：处理完（含豆瓣头像补齐）仍没有任何头像的演员从条目演员表移除；与「删除仍无中文的演员」叠加可实现只保留有头像且有中文信息的演员表。
- 运行报告与插件网页的说明列显示每条移除了哪些演员；dry-run 预览同样可见删除名单。

## 0.2.9 - 2026-10-31

- 设置页枚举值改为中文：处理条件（全部/演员非中文/角色非中文）、头像策略（保留现有头像/豆瓣优先/不改动头像）；旧版存的英文值自动迁移，升级不丢配置。
- 媒体库设置直接填中文名（如：电影、国产剧），兼容数字 id；运行时经 library.list 解析，写错的名称记警告并列出可用库。

## 0.2.8 - 2026-10-31

- 字形变体映射补全：実/实、恵/惠、姫/姬、穂/穗（日文新字体 → 简体）。

## 0.2.7 - 2026-10-31

- 姓名匹配兼容日中字形差异：TMDB 保留日文原字（日野聡、瀬戸），豆瓣转简体（日野聪、濑户），归一化时折叠常见字形变体（聡/聪、瀬/濑、戸/户、辺/边、澤/泽等 18 组）。
- 中文名匹配增加包含兜底：豆瓣常把假名名字转译成中文（上坂すみれ → 上坂堇，归一化后只剩“上坂”），精确匹配失败后做包含匹配（短侧至少 2 字），歧义仍交给角色收窄、不唯一就放弃。

## 0.2.6 - 2026-10-31

- 剧集匹配改为合并多个豆瓣条目：同一部作品按季拆条目、各季演员互有出入，此前取第一个有匹配的候选导致覆盖不全；现在合并前 5 个候选（季条目 + 总条目）去重后统一匹配，动画/长剧集覆盖显著提升。

## 0.2.5 - 2026-10-31

- 修复头像断链：NFO `<thumb>` 不再写本机头像绝对 URL（头像目录清理/换档后即失效），归一化为 TMDB original URL——主程序吸收后还原为路径，头像文件缺失时自动重新下载，详情页随时可回退图床。
- 未匹配演员的本机头像地址也一并归一化；已有条目下一轮运行自动改写修复。

## 0.2.4 - 2026-10-30

- 插件页主题恢复为最初设计：透明背景、透出主程序玻璃质感、颜色跟随 `--mc-*` 注入变量，不再固定深色。
- 前提：MoviePilot Tools 已升级到 v2.1.1（嵌入判定收紧后不再往 MovieClaw 插件页注入浅色样式），防御性的固定深色与强制 JS 随之撤除。

## 0.2.3 - 2026-10-30

- 插件页对全局换肤脚本/扩展主动反击：用 JS 写内联 `!important` 的深色底/浅色字/`color-scheme: dark`（内联优先级高于任何注入样式表），每 1.2 秒自检并在 `<head>` 注入时立即恢复。
- 实测定位：默认 Profile 白屏由某个扩展/用户脚本注入浅色样式导致（无痕默认禁扩展、无扩展的新实例都正常）；典型嫌疑是篡改猴里匹配全站的浅色/护眼脚本。

## 0.2.2 - 2026-10-30

- 插件页改为固定深色：本地定义 `--mc-*`、`html/body` 深色底浅色字、所有元素 `forced-color-adjust: none`，不再依赖主程序主题，也不受 Edge 强制浅色覆盖。
- 页面加 `Cache-Control: no-store`；排查 Edge 旧缓存时可用新查询串（如 `?debug=1&v=2`）强制重新加载。

## 0.2.1 - 2026-10-30

- 修复 Edge 把 iframe `color-scheme` 强制成浅色、白底/深字覆盖插件页的问题：`html/body` 用 `!important` 固定深色与透明底，并关闭 forced-color-adjust。
- `?debug=1` 可复核 `colorScheme` 应变为 `dark`、`htmlBg/bodyBg` 透明、`bodyColor` 为浅色。

## 0.2.0 - 2026-10-30

- `?debug=1` 的主题诊断改为延迟 1.5 秒读取并在主题切换后刷新，能拿到父页面注入后的最终 `--mc-*`、`html/body` 背景与颜色。
- 页面补 `html { background: transparent }`，避免部分浏览器给 iframe 垫白色底。
