# Changelog

## 0.1.0-beta.1

- 展示名统一为“123 云盘个人账号”，清单版本改为0.1.0-beta.1；稳定ID、包名、网盘类型与权限不变。
- 更新入口、后端及展示元数据，保留扫描、上传恢复与许可正文缺口。
- 此版本重新执行离线测试、官方校验和确定性打包；不包含真实服务验收，alpha.5反馈仍是历史记录。

- 补充自包含开发命令、官方要求对照及可独立运行的契约差异检查。
- 更正urllib3-future-request缺MIT正文的审计边界，补充来源记录；其余许可证原文保留。
- 明确许可证归属、验证边界和提交排除规则；保留 alpha.5 业务逻辑与依赖锁。
- 使用新版本生成本地安装包，旧alpha.5包及校验文件移入系统废纸篓；不自动安装或发布Release。

## 0.1.0-alpha.5

- 修复目录选择器对普通文件名也应用新建名称禁字符规则的问题；先区分Type，仅验证所需目录名称。
- 远端合法标点和Unicode原样保留；目录显示路径和扫描仍拒绝分隔符、点路径段、NUL等歧义。
- 全量扫描不静默跳过坏名，上传新建名称规则保持独立。
- 117项离线测试通过；真实触发项尚未确认；维护者随后反馈真实目录选择复测通过，其他服务能力仍待独立验收。

## 0.1.0-alpha.4

- 启用逐目录完整分页扫描，返回相对路径、全部文件和空目录ID；明确披露原生整树契约差异。
- 使用正式PLUGIN_DATA加密保存上传写前意图、会话、连续确认进度和提交状态；支持跨进程及宿主checkpoint丢失恢复。
- PUT丢ACK重传同键同片同字节；初始化/合并结果不确定仍安全阻塞，保留P1防护。
- 增加真实SDK/RPC跨进程退出测试及离线响应结构脱敏工具；无真实服务、安装部署或核心改动。

## 0.1.0-alpha.3

- 修复本进程已确认上传/秒传后重复 begin_upload(None) 被永久拒绝；重新读取原远端 ID 并核验名称、目录、大小、MD5后允许复用。
- 远端内容、名称、目录变化返回 Conflict，删除或回收返回 NotFound；不返回陈旧完成记录。
- 未确认结果仍禁止重复初始化；进程重启后不沿用内存完成保证。
- 新增6项测试，全量61项通过；扫描与跨进程恢复契约阻塞保持不变。

## 0.1.0-alpha.2

- 删除未经来源确认的个人分片进度解析；重启恢复明确失败，保持完整契约发布阻塞。
- 修复占位元数据被当成上传完成；同名复用须服务 Reuse 确认及远端目录/大小/MD5 核验。
- 增加当前进程初始化/分片/合并确认记录；响应丢失和取消不推进状态，不盲目重放合并。
- 合并确认后 stat 失败仅重试 stat；重复分片必须字节相同，拒绝伪造进度。
- 上传完成请求补 fileSize；秒传与合并核验 ParentFileId。
- 下载显式保留已核实 fork 的 platform=android，TTL仍为300秒。
- 55项离线模拟/契约/Runner测试；真实服务和完整恢复均未验证。
