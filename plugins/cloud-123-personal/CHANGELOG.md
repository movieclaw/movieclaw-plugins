# Changelog

## 0.1.0-beta.1

首次发布 123 云盘个人账号插件，使用独立的插件 ID、包名和网盘类型，与 OpenAPI 版共存。

- 通过正式表单登录接入手机号和密码认证，使用宿主加密认证存储，支持凭据更新和验证码错误分类。
- 提供目录选择、完整分页扫描、文件元数据、目录创建与删除；保留远端名称并校验无法表示的路径。
- 提供下载链接，默认缓存有效期300秒；不把 MD5 或本地哈希当作远端 SHA1。
- 支持顺序分片上传、秒传确认核验，以及基于加密 ACK 日志的跨进程恢复。
- 包含契约测试、严格契约差异检查、锁定依赖及第三方许可通知。

当前扫描为逐目录分页遍历，尚不满足原生整树要求。上传恢复依赖持久化确认；初始化或合并结果不确定时明确停止，不猜测成功。真实服务验收仍需由用户完成，详见 [README](README.md)。
