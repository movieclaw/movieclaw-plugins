### urllib3-future-request 0.0.2 — license evidence gap

The wheel METADATA and same-version source distribution's `pyproject.toml`
declare **MIT**, authored by ChenyangGao. Neither artifact contains a LICENSE,
COPYING or NOTICE file. This directory intentionally contains an evidence note,
not a fabricated or borrowed license text.

Verified public artifacts:

- [PyPI 0.0.2](https://pypi.org/project/urllib3-future-request/0.0.2/)
- `urllib3_future_request-0.0.2-py3-none-any.whl`: SHA256
  `eb7ae341a03defeca7f9c426721896a20300053193552db1ae36ad0ae0a96d26`.
- `urllib3_future_request-0.0.2.tar.gz`: SHA256
  `4a235dab9e53c3dbd7acc52b22ae5b57dceba4948171ba5e01ead52b5bf93245`.
- Declared [source directory at c12972eb199314fa6a332f0cdc1756ecd3a89bcb](https://github.com/ChenyangGao/python-modules/tree/c12972eb199314fa6a332f0cdc1756ecd3a89bcb/urllib3_future_request).
  That directory and repository root also have no license text at this commit.

The sdist says `license = "MIT"` and requests inclusion of `LICENSE`, but the
published archive omits it. The dependency is installed separately from its
unchanged, hash-locked wheel; its code is not bundled with this plugin. An MIT
metadata declaration is evidence of intended licensing, not evidence that the
original copyright notice and full license text were reviewed. Obtain the
missing original notice/text from upstream before claiming a complete release
license audit. Do not replace it with a neighboring package's LICENSE.

Checked 2026-10-20. No dependency version or runtime code was changed to conceal
this packaging omission.
