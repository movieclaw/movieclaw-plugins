# 更新记录

## 0.4.7

网页批量异名改名与按目标目录批量移动；扫描只点名本作品的网盘目录，旧文件先保留、逐条确认后才清理。

链接受理与识别

- 115 分享链接、ed2k、磁力先持久化成受理任务，再复用 MovieClaw 自己的识别链（`dl.resolve-target`）：同批活跃任务复用，不同批次不串单；网络中断在原检查点续跑，不重新转存。
- 执行前复查最新库存，查库失败不当作「没有」；候选冲突、无候选、TMDB 标记互相矛盾一律停下等人确认，绝不自动猜一部。

转存与归位

- 转存后只扫描本次作品的网盘目录（`library.scan.start` 的 `cloud_paths`），不再触发整库扫描；范围信息无效时明确停止，不悄悄降级为全库。
- 实际视频归位从「每个文件改名一次、移动一次」改成「批量改名，再按目标作品/季目录分组批量移动」：40 集、同季、每集要改名的情形由 80 次写请求降到 2 次。每批 50 项是插件的保守分块，逐批顺序执行，不提高并发、不放开原有单账号限速。
- 有开放平台授权时优先走 OpenAPI 批量移动；没有授权沿用网页批量移动，批量异名改名始终走网页接口（115 开放平台没有这个接口）。
- 每次批量写请求前后按目录读取完整清单，用文件 ID、名字、体积及可用哈希逐项确认；同名、大小写冲突、外部改名、体积变化都停下，不覆盖。回执丢失不盲重发，先回查真实结果，部分成功先保存成功项再补剩余项。
- 命名与显示语言分开：命名使用全局有效语言与库级覆盖，中英文片名分别取公开元数据的中文、英文或原名字段；没有对应语言的命名译名时明确停止，不拿英文回落冒充其他语言。

库存核验与清理

- 同一季集只留最大一份，SHA1 + 体积 + 名字三重核验；字幕失败保留并带检查点，只清空暂存目录里的已知残留，不删未知内容。
- 普通转存不再自动删除旧文件：核验新文件更大后先保留旧版，记录待清理数量。清理要走独立入口，先逐项预览旧路径、体积、替代文件与宿主删除演练结果，确认具体清单后才入队（15 分钟确认票据、精确编号核对、加密快照、去重）。
- 洗版临时名恢复与历史修名同样批量化，旧检查点继续兼容。

网页工作台

- 侧栏「115 入库」：提交框（与企微入口同一套受理）、转存与核验进度、失败重试与候选确认、空暂存目录清理、待清理旧文件预览与确认。
- 看板隐藏时停止轮询、重新可见后刷新；接口失败逐步退避到最多 120 秒。短查询由 1 秒逐步退让到 10 秒，有进展即恢复频率。
- 115 明确的 405 / 429 按限流处理并读取 `Retry-After`；安全验证文案按风控暂停，不误报成必须重新登录。

安全与权限

- 独立进程运行、联网；宿主操作仅 `dl.resolve-target`、`discover.get-title-details`、`library.list`、`library.items.get`、`library.scan.start`、`library.items.delete-file`（危险，仅在确认为旧文件后使用）、`jobs.show`、`jobs.list`、`jobs.retry`、`jobs.cancel`、`scrape.show`。
- 只读申请宿主 NER 模型目录（`/app/models/torrent-ner`），经文件接口读取后在插件私有临时目录中使用，不改模型、不写媒体目录。
- 侧栏只有「115 入库」一项，管理员可见；网页以打开它的人的身份运行。
- 原链接、提取码与检查点加密存储；日志与报错里不出现 Cookie 与令牌。
