# 115 分享转存入库（`p115-import`）

把 115 分享链接、ed2k 或磁力链接转存进 MovieClaw 媒体库。插件复用宿主的作品识别、分库、命名和季集仲裁；转存后只扫描本次作品目录，并核验库存。

## 使用

1. 在左侧打开 **「115 转存」→「设置与登录」**，选择没有被其他工具使用的登录端，用 115 App 扫码登录。分享转存和批量异名改名需要网页登录。
2. 可选：填写开放平台 AppID、保存并扫码授权；授权后文件操作优先使用可用的官方接口。未授权时使用网页接口。
3. 在提交框粘贴链接并提交。需要结果通知时勾选「完成通知」，随后在工作台查看进度、处理候选或重试。

也可通过命令操作（以当前服务器的 `--help` 为准）：

```bash
mclaw plugins p115-import apply --link '分享链接'           # 仅预演
mclaw plugins p115-import apply --link '分享链接' --yes     # 提交转存
mclaw plugins p115-import apply --link '分享链接' --notify --yes
mclaw plugins p115-import board
mclaw plugins p115-import request --job-id '任务编号'
mclaw plugins p115-import resume --job-id '任务编号'
mclaw plugins p115-import status
```

受理成功只表示任务已登记；以任务返回的 `inventory_verified=true` 为核验入库完成。电驴和磁力依赖 115 云下载资源与离线配额，不能保证成功。

## 通知与升级

通知交给 MovieClaw 的统一通知机制，按管理员在「账号 → 通知」中对 **115 转存通知**设置的偏好和已绑定渠道发送；不再需要为本插件填写企微推送地址或接收人。网页提交默认勾选通知，命令行按需加 `--notify`。系统通知为实时投递，不保证离线期间送达。

核验入库且已确认 TMDB 身份时，通知附带公开的 TMDB 作品链接，兼容支持图文的通知渠道；没有确定身份或取图失败时以实际渠道的能力显示。是否显示企微图文由所使用的企业微信通道决定，并非本插件单独保证。通知不应包含原始分享链接、磁力或提取码。

从旧版升级时，已有设置首次迁移到插件加密数据中，旧配置保留供回退；原来的企微推送地址不再参与发送。请在升级后检查管理员的通知偏好和绑定渠道。

## 安全与清理

- 同一季集以体积较大者为准；旧文件不会因普通转存自动删除。清理旧文件需先预览具体路径、替代文件与删除演练，再单独确认。
- 识别冲突、信息不足或范围扫描路径无效时停止并等待处理，不自动猜测作品或悄悄扫描整库。
- 原链接、提取码及任务检查点存于加密的插件数据中；结果通知会隐藏分享链接和提取码。
- 独立进程运行，需要联网及只读 `/app/models/torrent-ner`；需要查询作品、媒体库和任务、启动扫描、管理任务及读取刮削设置。另申请危险操作 `library.items.delete-file`，仅用于用户单独确认的旧文件清理。
- 侧栏网页仅管理员可见。网页以打开者身份运行，管理员打开时拥有管理员权限。

## 已知限制

- `/app/models/torrent-ner` 是容器的默认模型路径；非容器或自定义模型路径部署需要相应调整插件路径授权和代码。
- 作品命名语言取不到对应译名时会停止，不拿其他语言冒充；批量操作采用保守分块并遵循账号限速。
- 开放平台不提供分享转存接口，分享转存仍需要 115 网页登录。请选择未被其他工具使用的登录端，避免互相踢下线。
