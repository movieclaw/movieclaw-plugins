# 115 网盘

## 0.1.0-beta.3

- 整树列举带上被列目录的路径链（115 列目录的响应里本来就有，不多发请求）。配合新版 MovieClaw，网盘里有变化时
  只重新列有变化的那个目录，不再把整个库文件夹列一遍（#986）；老版本 MovieClaw 照旧可用。

## 0.1.0-beta.2

- 请求改走 MovieClaw 的网络出口：主程序按请求限速，整树列举翻的每一页都排队领名额、计入每日预算，
  大文件夹纳管不再连发几十页把 115 打到限流（#907，需要带按请求限速的 MovieClaw）；「网络与代理」里给本插件配的代理也生效了。

## 0.1.0-beta.1

- 首次内测。扫码登录（可选登录端）与浏览器 Cookie 导入；账号容量；目录选择、整树列举与操作动态（纳管）；
  文件核验、按播放器 User-Agent 取直链；秒传（含区间校验）与 OSS 分片续传上传；删除进 115 回收站。
- 依赖 `p115cipher`（115 的请求加密）与 `p115pickcode`（提取码换文件 id），均为 MIT 许可，安装时经管理员批准下载。
