# 更新记录

## 1.1.0 - 2026-10-22

按上游 review 修正，行为更保守、失败不再被静默吞掉。

- 订阅失败分「临时」和「永久」两类：5xx、超时、鉴权过期、429 这些下一轮会重试，不再写进 `done` 名单（此前一次网络抖动就会让这条想看永久失联）；只有明确的 4xx 才算永久失败。临时失败也不占本轮预算，`remaining` 也如实计入。
- 拉取豆瓣列表遇到 403 / 429 / 5xx 会退避重试（2s、4s、8s，最多 3 次），风控限流等一会儿多半就过；403 的报错文案区分「收藏没公开」和「豆瓣在限流」两种情况。
- 基线时间参与二次拦截：`done` 名单只有 800 条，攒满后老条目会被挤掉、下次翻到会当成新的重新订阅。现在每条想看还要和首次同步的基线时间比一次，早于基线的直接跳过。
- 选季核对：`subscriptions.create` 返回后检查 `selected_seasons`，宿主把季丢掉时如实回执并告警（`seasons_missing`），不再当成订阅成功。
- 补 `LICENSE`（MIT），`store.json` 的 `license` 由「见仓库许可证」改为 `MIT`。
- 为 `baseline_string` / `is_permanent_error` / `seasons_missing` 补单测。

## 1.0.0 - 2026-10-20

首个版本。

- 盯住一个或多个豆瓣账号的「想看」，按定时任务把它同步成 MovieClaw 订阅。
- 只处理最近 N 天内的想看，N 可调（0 = 不限时间），避免把很多年前的老片一次性订进来。
- 第一次同步默认只记基线：窗口内已有的想看当历史，之后新点的才订阅；也可以在设置里改成「连已有的也订」。
- 电影直接订；剧集按标题里的「第 N 季 / 第 N 部 / Season N / S0N」选季，没写季号按第 1 季，季号在 TMDB 里不存在时退回「只追以后播出的新集」。
- 剧集可按设置打开「自动续订」，以后播出的新集、新季自动追。
- 已经有订阅的跳过；豆瓣条目对应多部作品或 TMDB 暂未收录的记进「待确认」，用 `pending` 看、`resolve` 定，不自己瞎猜。
- 每轮最多订阅 N 条（1～50），剩下的下一轮继续，避免一次点一堆把任务压满。
- 只读豆瓣公开的收藏列表，不需要也不接受账号密码；接口地址可在设置里换成镜像或反代。
- 订阅成功时发出一条 `douban-wish.subscribed` 事件，可按默认订阅生成被动通知。
