# 维护者审查导览

## 加载与数据边界

`movieclaw_friends.__init__` 导出 `native.apply`。宿主以隔离包名加载，使用 `HOST_OPS`、`PLUGIN_ROUTES`、`PLUGIN_FILES` 登记本人登录区和签名公开区。后台循环通过宿主任务生命周期启动、取消与释放；无独立监听端口。`app.create_app` 是可注入上游的业务与测试载体，正式安装不提供独立登录服务。

| 边界 | 实现 | 需重点核对 |
| --- | --- | --- |
| 宿主身份 | `native.py`、`native_source.py` | `require_login` 为宿主 Python API，inline 无沙箱；插件能力身份不能冒充真人 |
| 插件数据 | `store.py` 与各业务模块私有表 | 只在 `PLUGIN_FILES` 分配的目录打开 SQLite；凭据本地加密，密钥与备份均需保护 |
| 本人设备授权 | `native_sync.py` | MovieClaw 正式设备配对，持续复核账号；可选本机接口地址与联邦公开地址分开，地址变化拒绝复用旧凭据；不读取宿主数据库、配置密钥或浏览器令牌 |
| 外部平台 | `external_watch.py`、`external_alignment.py` | Emby API 密钥须绑定指定本人账号，Plex 令牌绑定其账号；不把地址和令牌返回浏览器 |
| 公开投影 | `media.py`、`display_policy.py`、`community.py` | 白名单、排除库、来源未确认时拒绝公开，重新读取时再核对，不因导入而自动分享 |
| 同步写入 | `watch_alignment.py`、`auto_sync.py`、`resume_sync.py` | 精确身份、本人范围授权、条目锁、持久意图与响应丢失后只核验；不是整个历史流水复制 |
| 网络边界 | `peers.py`、`network*.py`、`discovery.py` | 公网 HTTPS、固定 DNS 连接、禁止重定向、限流／大小／时效／签名；公共发现不继承私网例外 |
| 原生网页 | `movieclaw_friends/static/` → `web/` | `tools/build_web.py --check` 防止生成产物漂移；当前账号读取图片／资料，不使用对端媒体编号打开本服资源 |

## 关键授权路径

1. 私人导入：连接并验证本人账号 → 只读任务 → 查看预览 → 确认存入插件私人档案。
2. 手动已看对齐：读取各选定账号库存 → 确切作品及季集匹配 → 用户逐项确认 → 通过平台业务 API 补已看 → 回读。
3. 后台同步：默认关闭 → 本人选择连接、方向和库 → 明确保存授权。已看与续播分开开关，停止／撤销后不再提交新请求，在途请求可能完成。
4. 本服／跨服公开：选择具体字段 → 获取当前预览 → 预览令牌核对 → 明确同意。私人好友访问、可信互联传播、公共发现分别授权。
5. 可信联邦：管理员双方批准节点 → 来源签名公开快照 → 最多两次传递，原来源五分钟租期不能被中转延长。公共发现另用独立用途签名和用户授权，不自动信任陌生服务器。

## 验证分层

- 官方 CI 使用固定 v0.42.0，执行清单／契约检查和 29 项 unittest 核心检查。核心检查真的走宿主隔离加载、二次加载和资源释放；其余完整场景用 pytest。
- 完整 pytest 含业务 HTTP、SQLite、模拟 Emby/Plex、受控多实例、Chromium 网页交互；不使用私人线上凭据，不写真实平台状态。
- 建议 v0.41.0+ 运行全部 Web 功能。固定基线契约检查通过，不代表其他版本所有接口或 UI 均一致。
- 真实第二台互联网服务器和公共入口尚未提供，不能将本机多实例验收表述为真实多服联调完成。
- 本 PR 不包含服务器地址、账号令牌、插件私有数据库、构建安装包或用户页面截图。发布标签与商店索引由维护者按仓库流程生成。

## 已知限制

`inline` 插件与宿主进程同权限，清单的三个只读操作不能限制 Python 本身的能力；须审查源码并由安装管理员单独批准。已看同步不复制原平台观看次数、时间线或完整流水。续播为轮询式，剪辑／时长／活动会话核验不通过时跳过，不保证所有客户端即刻衔接。关闭分享可停止后续访问及短期缓存展示，但不能删除截图、人为导出或不遵守协议的远端副本。
