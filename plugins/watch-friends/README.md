# 映迹 · v0.1.2

映迹涵盖观看足迹、片单、推荐、三平台已看对齐与影友互动。当前版本为 `0.1.2`。安装标识 `watch-friends`、访问地址和私有存储位置保持不变，已有记录和连接无需迁移。

MovieClaw 原生插件，安装包为 `.mcplugin`。由现有服务器加载，Web 入口 `/apps/watch-friends`，不新增容器、服务或端口，不修改主程序代码、数据库结构、媒体文件或宿主片单。只有本人预览确认手动同步，或单独明确开启后台同步后，才通过正式接口更新所选本人账号准确匹配的电影或单集状态。所有好友关系、同意记录及分享快照写入插件自己的私有目录。

## 使用与隐私

- 使用 MovieClaw 当前登录账号，无需再登录插件或粘贴令牌。普通成员与管理员均可使用。
- 默认不公开、不分享、不添加任何好友。设置分别控制广场姓名、近期观看、喜欢电影及好友分享；可以只公开姓名和喜欢电影，不公开观影历史。公开前先预览并确认具体内容。广场显示的是确认时的快照，后续更新需重新预览确认。
- 同服广场展示本服自愿公开的账号；联网广场另行授权，见下方“受控影友互联”。没有中央目录，不相连的网络无法互相发现。跨服私人好友可从联网名片申请，或主动交换好友邀请码建立直连，双方都须安装本插件。
- 实际好友须发送方和接收方分别确认，之后按各自开关共享正在观看及最多五十条历史记录。未结束的播放不会混入历史，当前播放有时效。实际时效受宿主播放记录刷新影响。
- “我的片单”支持创建、改名、修改简介、增删影片、调整顺序、删除和分享，创建后默认仅自己可见。选片使用当前登录账号的影片搜索，也可创建空片单；搜索受宿主成员权限约束，不保存宿主搜索历史。编辑包含版本核对，其他窗口已修改时会提示重新打开，不覆盖新内容。私人编辑不会自动改写已分享的快照，仍需主动更新分享。
- “我喜欢的电影”支持反复增删选片，保存后默认仅自己可见。私人列表修改不会自动改写已经公开的快照；开启广场喜欢展示后，仍需重新预览确认才会更新。撤回对应授权或关闭广场会停止该名片的展示。
- “影友动态”提供本服推荐流和已确认跨服好友的推荐。支持 1～5 星评分，只打星即可发布，也可只写推荐理由或两者同时填写。发布前明确公开昵称、评分、推荐文字和所选作品，其他登录用户可以点赞、评论、收藏到私人喜欢或加入自己的插件片单。不会自动附带私人观看记录或服务器地址。推荐可由本人删除，并级联删除该帖互动；评论只能由其作者删除。动态推荐单独发布，关闭广场不会删除已发布的帖子。
- 跨服推荐需要双方已经同意好友关系，对方还需单独开启“跨服推荐动态”（默认关闭）。开启后，对方可访问本人已发布及之后发布的推荐；跨服评论只在帖主与该好友之间展示，不将其他用户的评论转发出去。关闭开关、屏蔽或撤销关系会停止后续访问。支持新的签名社交接口时，原有好友可自动升级能力；旧插件未支持时明确提示，不猜测未签名地址。
- 个人资料使用主程序账号头像、可填写简介。点击影友头像或姓名可查看主页；主页的近期观看和喜欢电影只使用本人已确认发布的广场快照，发帖或成为好友不会自动公开私人历史。头像和简介也会显示在本人发布的推荐、评论等身份位置。
- 通知包含好友申请、推荐点赞和评论，支持未读计数、分页、标记已读及跳转相应内容。通知摘要不保存评论正文、观看记录或服务器地址。屏蔽在本服双向隐藏内容并停止互动及好友数据访问，取消后可恢复仍有效的关系；跨服屏蔽绑定已验证的好友连接，不能通过撤销后重新申请绕过。
- 本服推荐和评论可举报，MovieClaw 管理员在设置的管理区审核、隐藏或恢复内容。举报快照及处理记录保存在插件私有库。联网名片内的公开推荐可以将举报加密提交给来源服务器管理员，在互联管理中审核。已确认好友的独立私有动态仍按好友关系屏蔽。
- 影片提供原生详情、影视搜索和资源搜索入口。页面按当前浏览器账号查询本服片源，核对可靠作品身份后显示“立即观看”或“选集观看”；不会使用好友服务器的媒体编号，权限不足或查询失败会显示“无法确认”。资源搜索进入宿主后由用户选择下载，插件不直接创建下载或订阅任务。加入已有片单不会自动改写曾经分享的快照，更新分享仍需明确确认。
- 已有宿主片单由浏览器使用本人宿主登录身份读取，界面只列出可编辑的自建片单。用户主动点击分享后，将名称和影片元数据白名单保存为本人的分享快照，最多五十个片单、每单五百项；修改源片单后需要重新分享。服务器不会借插件管理权限代读成员私有片单，也不把导入快照标为经独立认证的创建者证明。
- 服务器地址不出现在个人卡片或好友页面中。但跨服通信必须交换网络地址，双方确认弹窗明确提示对方可能记录地址和已获准的数据。邀请码包含通信能力，应私下交换。撤销会停止后续访问，无法删除对方已经导出的副本。
- 默认包含小映、阿川、小鹿、星子四位虚拟演示用户，以姓名旁的小字明确标识，无需添加好友即可查看。“设置 → 演示设置”内提供演示开关，主页面不显示开关，偏好保存在当前账号的插件私有数据中；关闭后隐藏好友、广场和片单中的演示内容，重新打开可恢复。管理员仍可在插件设置中统一禁用演示。开关不修改真实好友、个人片单或任何分享授权。
- 四位演示人物各有独立头像和二十部作品，目录共八十部经核验的真实电影，各人的正在观看、历史、喜欢及主题片单不重复。八份主题片单附作者头像；人物和观看行为为虚拟，电影与海报真实。在线演示人物以绿点显示并按一倍速推进，离线以红点显示且没有正在观看的数据；真实好友缺少可靠在线信息时显示“状态未知”。演示推荐中的点赞和评论仅保存在本次页面内，不会写成真人互动。主动收藏演示中的真实影片，仍会按你的操作保存到本人私有喜欢或片单。
- 当前观影、历史与片单中的影片均提供海报和详情入口。真实作品通过已核对的 TMDB 身份，以当前浏览器账号读取宿主详情；海报经当前宿主代理。缺少可靠外部身份时保留已授权的基础资料与海报占位，不拿对端本地编号猜测本机影片。
- 影友动态采用横版剧照信息流，桌面显示个人名片与影友侧栏，手机以单列浏览；片源、搜索与下载搜索入口收在每条推荐的“片源与更多操作”中。影友公开资料页包含大头像、可横向浏览的近期观看与喜欢电影海报架，可从个人资料设置直接打开。公开资料页不披露私人累计统计，只统计获准展示的内容；剧照按当前账号在可见区域读取，无法获取时保留完整海报。

八十部演示电影的身份、资料及来源链接保存在 `movieclaw_friends/demo_catalog.py`，于 2026-10-20 经宿主 TMDB 发现详情核验，包括[星际穿越](https://www.themoviedb.org/movie/157336)、[盗梦空间](https://www.themoviedb.org/movie/27205)、[楚门的世界](https://www.themoviedb.org/movie/37165)、[千与千寻](https://www.themoviedb.org/movie/129)等。海报保留安全的官方 TMDB 图片路径，不捆绑影片文件；片单示例不表示这些作品已在你的媒体库中。按钮强调色使用柔和银蓝，表面和文字仍沿用宿主主题。

## 本人主页与已看导入

导航首项“个人主页”以三行大号数字展示已看电影、电视剧和单集数量，千位数量缩写为 K，悬浮或辅助阅读可查看完整计数。展示主程序账号姓名、已设头像、首次进入插件的日期（旧账号按最早插件活动记录补齐并固定保存）与私人观影档案。首次进入时间固定保存，重新启用或升级不会重置；头像由本人浏览器从正式账号接口读取并转为 JPEG 缩略图后同步，其他用户读取插件绑定到原用户的缩略图，不共用宿主“当前账号头像”地址。导航采用本地打包的 Lucide SVG 图标，许可证位于 `web/lucide-LICENSE.txt`。真实账号不再选择演示头像。

统计分两组：已看电影数，以及已看电视剧数／单集数。以 TMDB 作品身份和季集号去重，跨来源和重复观看只计一次；待匹配条目保留在私人档案但不计入数量。主程序记录使用完整游标分页，仅导入宿主明确标为已完成的播放场次；这些累计数不从广场的五张展示卡片推算。主程序仅手动设置的已看标记没有播放流水，不能由播放历史反推成场次。

Emby/Plex 在“设置 → 把观影记忆带回来 → 连接账号”中由本人提供服务器地址和个人登录令牌。Emby 明确填写本人用户名或用户 ID：服务器 API 密钥可通过正式 `Users/Query` 精确匹配用户名，个人令牌无查询权限时直接填写用户 ID。随后固定 ID 读取该账号已看 Movie/Episode；Plex 只读取本人令牌可见的库条目已看状态，不使用能读取全用户的管理员历史接口。Plex 使用个人令牌；Emby 可使用个人令牌或服务器 API 密钥，但密钥不等于用户身份，必须明确指定并确认本人账号，不自动选择第一个用户。未绑定的旧 Emby 连接可点“指定 Emby 账号”修复，已绑定连接不能更换用户。地址和令牌加密保存于插件自己的私有目录，API 不返回明文。网络遵循宿主出口，默认公网 HTTPS；管理员可在插件设置允许私网和 HTTP。

连接后先生成预览，列出来源记录、新增、已存在与待匹配数量。可核对 TMDB 编号及季集，确认后才进入私人档案。来源提供的最后观看日期会保留；没有日期时不伪造。来源的已看条目状态不等同于每次播放的历史流水。重新读取同一连接可重复导入且幂等；断开连接删除凭据、停止任务并使旧预览失效，也可同时移除该来源的私人档案。

导入成功后，可另选“预览主程序已看标记”：使用当前浏览器账号查询本服可访问条目与已看状态，只为精确匹配的电影／单集生成列表，已有标记跳过，无片源或匹配失败保留在插件。勾选确认后才逐项写入，电视剧绝不因一集而级联标为整剧已看。提交前再次核对登录账号和作品身份；部分失败可重试，成功项跳过。不改收藏、不虚构进度或播放流水、不修改外部平台。关闭窗口停止后续提交，已完成的标记保留。导入不会自动发布到广场、推荐流或好友共享快照。

真实外部账号的联网验证需由本人填写有效连接；自动化验收使用受控 Emby/Plex API 样本和本机宿主账号，不使用生产凭据。

## 受控影友互联（直连与两跳名片）

入口为“设置 → 影友互联 / 联网广场”；浏览入口为“开放广场 → 联网广场”。继续使用现有纯插件、宿主签名接口与插件私有存储，不新增容器、端口或宿主写权限。服务器总开关、本人发布、继续转发、浏览外服、喜欢/推荐/近期观看均默认关闭，升级不会继承旧广场或好友共享授权。

管理员先开启服务器互联并确认网络地址提示。A 生成三十分钟、单次使用的服务器连接码交给可信的 B 管理员；B 粘贴连接码、命名并确认申请，A 在管理区核对签名身份后批准。两边批准后开始每分钟获取名片。可以停用、恢复、屏蔽或移除服务器，支持重试连接和两阶段凭据轮换；屏蔽也拒绝该来源经其他节点转来的名片。连接码、网络地址、签名接口和连接凭据均不进入普通成员的名片响应；后台加密保存连接信息。默认只允许公网 HTTPS，局域网互联仍须管理员显式开启原有私网选项。

互联管理明确显示“已保存”或“有更改待保存”。网络地址确认只在首次启用或停用后重新启用时填写，保持启用后再次保存无需重复确认；添加服务器仍逐个确认。开启联网浏览后，本人已发布名片会在联网广场置顶显示，即使尚未连接其他服务器也能核对内容；本人名片不显示申请好友、屏蔽或远端互动操作。本人视图同样受账号有效性、当前媒体库排除和撤回规则限制。

用户可只开启“显示外服影友”，无需公开自己。发布时选择喜欢影片（最多十二部）、已发布推荐（最多六条），近期观看需另外勾选（最多五条，包含已确认导入的记录）；预览会显示头像、昵称、简介及具体影片/评分/推荐文字，勾选地址与传播提示后才保存。快照不会自动加入后来导入、新增喜欢或新发推荐，需重新预览确认。媒体库排除、来源未核实规则、推荐删除及管理员隐藏仍在每次输出时重新检查。原始观影档案、播放设备、播放/下载地址和好友凭据不传播。

未勾选转发时，名片只到直连服务器；允许转发时，A→B→C 最多两次传递。来源使用持久 Ed25519 身份签名内容、版本、传播上限及五分钟有效期；每个中间节点追加签名证明，不能修改内容、移除有效跳数或延长来源租期。来源续签前还会复核宿主账号是否仍然有效（结果最多缓存一分钟）；停用、删除或复用编号的成员不再为旧名片续期，租期不能超出最后一次有效核验后的五分钟。接收侧按来源身份与用户编号去重，防止旧版本和已撤回版本重放，拒绝循环和超跳数。屏蔽外服影友仅影响本人浏览，可在设置解除。

撤下立即停止来源输出并向已连接节点发送带签名的撤回通知，收到通知的中间节点最多再传递一次。离线节点或通知失败时，旧名片五分钟到期隐藏；浏览页面定时刷新及按来源到期时间清除内容。截图、人工保存或不遵守协议的副本无法强制收回；页面不显示地址也不等于匿名。服务器时钟应保持准确，过期或超前过多的名片会被拒绝。

第一版每台最多八个可信直连节点、每个目录最多二百张名片，采用固定分页、请求/响应上限、限流和超时。暂不向整个互联网自动发现服务器，支持在可见的具体推荐上点赞、评论、删除本人评论、举报和申请好友；这些动作逐项授权，不自动建立私人好友。私人访问仍须双方同意。联网广场发现与三平台已看同步完全独立。

## 三平台已看对齐（手动确认）

“设置 → 把观影记忆带回来 → 预览三平台已看对齐”可选择当前 MovieClaw 账号及已绑定的 Emby/Plex 连接。先只读核对最新已看状态（包含 MovieClaw 手动设置的已看标记），结合已确认的私人足迹，按 TMDB 身份与季集号合并。预览不导入私人足迹，也不回写任何平台；沿用媒体库排除规则，来源未核实的内容不借其他副本绕过排除。

预览按平台显示待补标、已看跳过、缺片源、匹配不唯一和核验失败的数量，可筛选、逐项勾选，再勾选明确确认框同步。整剧显示合并不影响同步粒度，回写始终是具体电影或单集，绝不整季或整剧级联。MovieClaw 由本人浏览器使用当前登录身份回写；外部平台使用私有连接中已绑定的账号，浏览器不接收外部地址、令牌或写入编号。

回写前重新核对账号、媒体身份、库归属与已看状态，回写后读取状态确认。只补已看，不撤销、不改收藏评分、不发送进度或伪造播放流水。观看日期、次数不复制，外部平台可能记录本次标记时间。成功项再次提交会跳过；提交结果不确定时，重试只核验状态，仍未确认则需重新预览再决定是否补标，避免重复增加播放次数。

计划与结果仅本人可见，写入授权有效期一小时，可“查看上次对齐预览”。历史结果可长期回看；连接或媒体库范围改变后，旧计划只能查看，写入须重新核对。关闭窗口停止后续提交，已开始的单项请求可能完成，已完成结果保留。原有本人确认同步保留。三平台后台补标及独立续播同步见下文，各自授权，不会随更新自动开启。

## 后台自动同步已看（MovieClaw / Emby / Plex）

设置 → 把观影记忆带回来 → 后台自动同步已看。新账号默认关闭，升级保留既有授权；选择至少两个已验证的本人连接、同步方向和媒体库，勾选确认后保存开启。支持只读取、只接收和双向同步，每 15 / 30 / 60 分钟检查；首次开启也会核对所选范围内已有的已看内容。媒体库默认不勾选，新连接和新媒体库不会自动加入。同步范围与对外展示范围独立；选择私人库只授权本人账号之间补标，不改变广场、足迹或统计的展示设置。

循环在宿主登记的插件后台任务中运行，关闭网页仍继续；暂停、停用插件或卸载会停止后续请求，已发出的单项请求可能完成。连接失效、账号变化或范围调整会阻止旧任务继续提交。支持 Emby/Plex；MovieClaw 需另外配对本人设备并勾选范围后才加入。不开启 MovieClaw 后台授权时仍可使用原有确认同步。不取消已看，不复制时间、次数；续播使用独立开关。只使用本轮实时库存中的已看作为证据，不将旧导入足迹重新当作观看事件；TMDB 身份及季集必须精确，重复副本、缺片源及编号不明的内容不自动选择。

每项写入前重新核对来源已看证据及目标身份、账号、库范围；与手动同步共用条目锁。写入意图先存插件私有库，写后回读。丢失响应和插件更新后只核验已提交项目，不盲目重发；后台曾成功补标后被手动取消的条目也不会自动覆盖，须到三平台确认同步重新核对。写前未提交的连接失败可以在后续检查重试。平台自身可能记录补标时刻，后台不伪造观看流水。

设置页可查看最近检查、下次检查、读取阶段、已处理／总数／剩余、各连接的成功、失败、待核验与缺片源等数量，并打开逐项明细。全部自动同步历史已接入观影数据任务中心并提供分页，包含每轮总量、剩余量、平台汇总和条目明细。选择历史条目可重新生成只读对齐预览，确认后再补标；查看历史不触发写入。可立即检查或暂停；连续无补标的成功轮询仅保留最新一轮，真正提交的结果保留。所有配置、执行记录、凭据和结果按本人隔离，凭据不返回页面。

## MovieClaw 本人设备配对

在后台同步连接列表点击“配对 MovieClaw 本人账号”，核对配对码后由本人打开主程序的 `/activate` 页面批准“映迹 · 本人观影同步”，再点“已批准，检查配对”。插件只调用正式设备授权、令牌交换和本人业务接口，不读取或截获浏览器登录凭据。批准账号与当前原生登录账号必须一致；成员还会持续复核创建时间和有效状态，不能借管理员授权写其他成员。设备凭据加密存于插件私有目录，网页和 CLI 不返回明文。撤销后台授权会删除插件凭据并尝试注销该设备；主程序“设备”页也可撤销。

配对需要**服务器自身能访问自己的 API**。默认使用主程序设置的外部访问地址；未配置时会明确提示，不再访问占位域名。如果浏览器能访问公网域名、但容器内不能通过该域名连回自己，管理员可在主程序的「映迹插件配置」中填写可选的 **MovieClaw 本机接口地址**（`native_api_url`）：填写同一 MovieClaw 实例在服务器／容器内可达的 HTTP(S) 源地址，保留必要端口，不加 `/api/v1`、路径、查询或凭据。该地址只用于本人设备配对和后台同步，不改变联网广场的公开地址，也不会出现在普通用户的配对响应和公开名片中。保存配置重新启用插件后，地址发生变化的账号须重新配对；未设置此项的已有正常配置保持原来的行为。

授权页使用当前浏览器同源的 `/activate`，不会把容器内部地址当成让用户打开的网页。连接超时、代理连接失败、证书校验失败、重定向、接口不存在及无效 JSON／响应格式分别提示，错误不回显地址、上游正文或凭据。不会自动关闭 HTTPS 验证或跟随重定向。证书异常需修复证书信任，或由管理员选择受信任的本机访问路径。修改目标后撤销旧授权仅清除插件保管的旧凭据，不把旧令牌发给新目标；旧设备如需注销，请到原服务器「设备」页处理。

配对不等于开启同步。MovieClaw 连接默认不选，配对后另选方向、媒体库并确认保存；原有手动确认同步一直保留。清单仍只有原来的三个只读宿主操作，没有申请全局代写成员的权限。

## 跨平台续播（独立开关，默认关闭）

设置 → 把观影记忆带回来 → 跨平台续播。沿用本次确认时已保存的同步连接、方向和媒体库，支持 1 / 5 / 15 分钟检查。保存绑定具体范围版本；另一窗口修改范围后必须重新核对。后续扩大已看范围不会自动扩大续播范围。首次检查只建立基线，不把已有大进度当作最新观看；之后以实际观察到的位置变化决定来源，支持向前播放和主动拖回，自己的写入不会作为新的观看再传播。

只同步未完成且低于片长 85% 的位置。电影和单集按准确身份匹配，多副本、不同剪辑标记、时长差超过 1%（最多五秒）、目标已看、两端同轮变化均不自动覆盖。写前再次核对来源和目标；目标正在播放或暂停时跳过，无法确认活动会话也停止回写。Emby 用户状态不完整时拒绝更新，防止重置收藏或观看次数。MovieClaw 续播还须确认单个文件版本。已发出但响应丢失的请求只回读，确认后修正历史任务，不自动重发同一位置事件。

续播任务也进入统一任务中心，可查看实时阶段、总量、剩余、结果及失败原因。关闭后不再发新请求，在途请求可能完成。它是后台轮询同步，受网络和客户端缓存影响，不承诺所有客户端即时衔接。平台可能记录同步时刻或同步设备；不复制原平台的播放日期、次数和完整流水。

## 互联连接恢复与公开互动

丢失连接申请响应时保留加密握手，可“重试连接”，对端只接受同一身份、凭据和随机挑战的原申请，不重复创建、不重新消费连接码。轮换连接凭据分“准备、提交”两阶段，丢包后重试恢复同一轮；提交后旧凭据失效，节点签名身份、用户授权和历史不变。移除会通知对端，离线时仍立即停止本服访问，缓存最迟五分钟过期。重新配对需要新连接码和管理员批准。

联网名片可直接申请私人好友，仍需双方确认服务器地址提示和各自共享范围，双方同意前不能读取私有记录。网络内推荐支持点赞、评论、本人删除及举报；向来源服务器发送互动前明确提示公开昵称、头像和相应内容。本服评论默认只在本服，另勾“同时公开到联网讨论”才发送到联网讨论区。来源管理员在“互联举报审核”隐藏、恢复或忽略推荐，操作留审计记录；本服成员也可举报联网评论。屏蔽互联影友后停止其互动并隐藏评论。

一至两跳互动使用 X25519 + AES-GCM 密封载荷、Ed25519 节点签名、逐跳证明和请求幂等键；中间服务器不读取好友邀请码或评论正文。公开名片不携带好友访问凭据。来源撤回、库排除、审核隐藏或账号失效后停止新互动。新互动能力要求来源与中转节点均升级到当前构建；旧节点不能通过猜测未签名地址绕过。没有实际外服时只验证受控多实例，真实多服长期运行仍需后续验收。

## 媒体库展示范围

进入“设置 → 媒体库展示范围”，点击“刷新媒体库与来源”，核对完成后勾选要排除的库并保存。支持本人可见的 MovieClaw 库以及已连接的 Emby/Plex 账号。核对只建立插件自己的私有来源索引，不导入影片、不改变已有导入预览，也不改外部或主程序的媒体库权限。不会按库名自动判断成人内容，需要本人选择。

桌面端按 MovieClaw、Plex、Emby 顺序为已连接来源分栏，随实际数量显示一至三列，小屏幕自动换行。已断开来源的卡片隐藏，但其排除规则仍保留，重新连接不会意外取消旧的隐私限制。

排除规则由服务端执行，覆盖旧广场名片、社区个人页、好友当前播放与历史、共享片单、推荐及其评论，并阻止发布被排除作品。任一来源命中排除库均隐藏；同一作品在其他允许库的副本不能绕过。至少选择一个排除库后，来源不明的旧记录也暂时隐藏，请先核对来源。媒体库名称、编号和连接地址不会出现在对外分享数据中。

“我的观看足迹与统计”提供两个独立选项：“从观看足迹中隐藏”和“不计入观看统计”。两项默认开启，可分别选择只隐藏足迹、只排除统计、同时排除或都保留；对外排除始终有效。统计排除涵盖电影、电视剧、单集及待匹配计数。原始私人档案和片单保留，设置拆分升级会继承原来的选择。取消排除可能恢复已有公开授权。其他人已经保存的旧副本无法远程收回。媒体库移动、重新归类后应重新核对来源。

## 原生接口与权限

清单入口 `movieclaw_friends`（实现位于 `movieclaw_friends.native`），运行方式 `inline`，以直接使用宿主已验证的 Principal，账号按成员 ID 和创建时间隔离。只通过正式 SDK 的 `HOST_OPS` 调用三个只读操作：`members.list`（核对成员仍有效）、`playback.history`（固定成员 ID）、`search.library`（只为已授权记录精确核对本地条目与库编号，补充公开作品身份）。不调用会发布浏览事件或启动播放预热的条目详情操作。不导入宿主数据库、模型或仓储，不保存宿主登录令牌。

使用 `PLUGIN_ROUTES` 注册成员区与签名公开区，使用 `PLUGIN_FILES` 定位自己的私有目录。路径授权为空，不申请媒体库读写权限。跨服网络使用宿主网络出口；默认要求公网 HTTPS，禁止重定向、限制响应大小，并固定已检查的 DNS 地址。局域网连接需要管理员显式开启。跨服需在 MovieClaw“设置 → 应用”配置可互相访问的外部地址。

Web 页面与宿主同源，使用打开页面者的身份运行；管理员打开时拥有管理员的网页权限。插件后端仅使用获批只读操作；网页以当前本人会话读取头像、作品和片单资料，单独确认后可通过正式 `playback/marks` 接口设为已看。没有插件管理员身份写入其他成员状态的接口。侧栏新增一个“映迹”入口；手机版网页从“我的 → 插件页面”进入。

观看足迹按 MovieClaw、Emby、Plex 的实际观看时间合并排序，缺少日期的记录置后，同一电影或单集保留最近一次时间。公开预览也读取已确认导入且允许展示的记录；查看预览不会改变授权，确认保存后才将这些导入历史纳入相应的广场快照或好友历史分享。旧的好友授权保持原来的主程序历史范围，直到本人重新预览确认。

“我的观看足迹”会自动核对作品目录及 MovieClaw、Emby、Plex 的完整正片片库目录，跨平台去重后的单集合起来看完也能合并，不再强制等待元数据将整剧标为完结。元数据完结且全部看完标“全剧已看完”；未完结但目录全集已看完标“目录内已看完”；按某个平台的片库目录或多个平台目录并集看完标“片库内已看完”，不声称未入库的未来剧集也已看完。不以已看列表的最大集号推测总数。按最后一集的观看时间排序，可点“查看单集记录”展开；漏集或目录未知时合并为进度卡，标注最高已看季集号及实际已看集数，不标成全集已看完。特别篇单列，不阻止正片合并。目录按本人缓存一天，可手动“核对全集完成情况”。仅改变私人足迹展示，不改原始记录、统计、对外分享或已看标记；读取目录不创建订阅或下载。通用集名“第47集／第四十七集／Episode 47”等不再与季集号重复显示，有实际内容的集名保留。


待匹配观看足迹可点击「校正匹配」，使用当前登录账号搜索 TMDB 作品并展示海报核对后确认。
同来源、同名同年份电视剧可选择批量修正其他待匹配单集，保留原观看日期和季集号。
修正记忆绑定本人、来源连接及源条目 ID；源条目变成其他作品时不套用，重新导入同一条目时沿用。
只有可靠作品身份的记录参与跨来源去重与统计；这项操作不写入三平台已看状态，也不更新公开快照。

观看足迹中的已匹配电视剧统一按作品合并，未看完也只显示一张卡片，标注最高已看季集号和实际累计已看集数。
尚未匹配的正片单集按同一连接、原片名与年份折叠，仍标注待匹配、不计统计，不跨来源合并或推测完结；可展开单集记录后核对匹配。
重新导入同一条目时，若作品和季集未变而本次暂缺元数据，会保留此前确认的作品身份和安全海报路径；来源明确提供不同身份时使用新数据。
重看早期单集不会使最高进度倒退，跳集不补算未看集数。卡片按最近观看时间排序，可展开全部单集记录。
全集完成标识仍需目录核验；本次仅改变展示，不修改来源事实、统计、分享范围或三平台已看状态。

账号连接、导入预览与三平台已看对齐集中到「设置 → 把观影记忆带回来」，个人主页仅展示资料、统计和观看足迹。
设置页依次为个人资料、媒体库展示范围、公开名片与好友分享、观影数据与同步、影友互联、演示设置；管理员举报处理位于最后。分区导航标明每块用途，手机页签可横向滚动。
各模块独立保存，以“已保存／有更改待保存”反馈状态，可放弃更改。未保存草稿只保留在当前标签页内存，切换页签或模块重新加载时恢复，刷新、关闭页面或切换登录会话后不保留；不会自动提交或扩展授权，预览中的确认框也不恢复。
媒体库展示范围尚有未保存更改时，先保存或放弃该草稿，再预览或开启分享；撤回已有分享不受影响，避免误将未生效的隐私选择当作已保存规则。
未选中的同步来源禁用其方向和媒体库选项。续播显示独立的已授权状态和本次待确认范围，可主动刷新候选范围，必须重新确认后保存才生效。联网浏览偏好和演示偏好自动保存，发布名片仍需具体内容预览；取消勾选发布后可明确保存并撤下。

常驻解释收进标题旁的信息图标，支持鼠标悬停、键盘聚焦、Esc 关闭和触屏点击。
足迹排序、统计口径、媒体库排除及来源标记等说明按需查看；错误、读取进度和操作结果仍显示。
公开发布、跨服好友地址暴露及同步写入的确认提示保留在相应操作中，不因精简页面而省略。


## 观影数据任务中心

「设置 → 把观影记忆带回来 → 任务中心」按时间列出本人导入与对齐任务，可筛选类型并分页回看。
导入明细支持按影片名、匹配状态和本次新增/更新筛选。确认导入时保存当时的新增原始记录、更新原始记录、跨平台去重后新增已看与已有数量；原始条目数与去重已看数分别展示，不混用。旧版本未保存的历史新增量明确标为未记录，不根据当前档案倒推。

对齐详情显示每个平台待补标、已看跳过、已同步、失败、缺片源及匹配异常数量。确认所选条目后，持久保存最近一轮的总量、已处理、剩余、各平台成功/跳过/失败及执行起止时间；条目保留执行次数与最近核验时间。界面每秒读取进度，未知读取总量只显示实际已读数，不伪造百分比。心跳超过两分钟或插件重新加载后显示中断，不自动继续回写；关闭窗口会请求停止后续提交，在途请求仍可能完成。

可在任意状态下选中有疑问的条目，点击「重新核对选中项」，按原账号和准确电影/单集身份生成一个新的只读任务，原任务结果保留。跨平台重核仍可能读取目标账号的完整目录，以验证片源、重复副本及排除范围，但仅为所选平台与作品生成目标。新预览需要再次勾选确认后才会补标，重核本身不写入任何平台。源账号发生变化时须新建完整预览。


推荐发布会区分「命中排除库」与「来源暂未核实」。普通影片无需先观看或导入：选择作品时按需通过已批准的 `search.library` 完整分页核对 TMDB 类型、编号及所属库，将确认的来源仅写入插件私有索引。核对接口不发布推荐，也不导入或标记已看；发布接口仍独立复核，不能绕过排除规则。同名但不同 TMDB 身份不作为匹配依据；查询失败或分页不完整保持未核实，可重试，不能误缓存为成人库命中。


任务中心默认按本人、来源连接和完整读取内容合并连续重复的已完成核对，保留首次导入、实际内容修改及失败任务；比较影片身份、资料、观看日期和次数，不按记录总数判断相同。合并发生在分页之前，勾选「展开重复核对」可查看每次原始任务及明细，不删除日志。新任务分开记录新增、实际修改和内容未变化，未变化的来源事实不重复写入；旧版的“更新”仅表示读取已有条目，界面按旧口径标示。自动打开页面会复用最近五分钟内的本人主程序成功读取，手动同步始终发起新读取；在途任务仍按本人和来源复用。

影友主页会独立读取作者已发布的公开推荐，展示影片海报、名称、星级、推荐文字及发布时间，并可跳转原动态查看互动；推荐较多时支持继续加载。未开启广场名片或没有公开近期观看、喜欢列表，也不会隐藏已经主动发布的推荐。主页沿用动态的媒体库排除、双向屏蔽、审核隐藏和删除规则；这不会扩大私人观影或喜欢列表的分享权限。

静态操作、空状态、海报缺省、评分与帮助图标统一使用随包提供的 Lucide SVG，图标源固定为提交 `c29c276f16590cf017126671535ad8c792be64d8`。运行时不访问图标 CDN、不加载图标字体；图案对读屏隐藏，按钮保留中文操作名称，点赞状态与评分仍通过原有可访问属性表达。许可证见 `web/lucide-LICENSE.txt`。


## 可选公共发现与本服广场

联网名片使用已经预览确认的同一份公开快照，在本服广场也可被其他本服用户看到；不会因此开启私人观看分享。联网发布撤下后，独立设置过的本服名片仍保留，否则停止在本服展示。媒体库排除、账号有效性和双向屏蔽在读取时重新过滤。

「设置 → 联网广场 → 公共发现（可选）」提供独立的公共发现开关、公共节点服务开关和最多四个入口。所有新增开关默认关闭，不内置公共地址，不自动把现有联网名片升级为公共发现名片，也不自动把本服作为公共节点。没有入口时显示尚未接入。管理员可在自愿提供公共节点服务后导出 `mcd1.` 接入码，由其他管理员手动配置；该码包含来源地址、签名入口与公开密钥，不包含好友访问凭据。无需中央服务、新增容器或端口。

用户另外勾选「允许通过公共节点被其他服务器的用户发现」，选择具体内容并预览确认，才能向公共节点发布。与可信连接的两次传递不同，此授权允许名片在公共发现网络继续分发；它不授予私人数据访问权。浏览公共名片无需发布自己。只有公开卡片进入目录，原始 Emby/Plex 导入档案不自动公开。

公开名片使用独立用途签名、来源身份及修订、最多五分钟有效期。节点不可改写内容或延长来源有效期。插件每分钟向已配置入口刷新；撤下或关闭后停止续签，尽力向入口推送撤回，离线副本到期隐藏。截图、人工保存和不遵守协议的副本不能强制删除。页面隐藏服务器地址，但通信服务器及管理员可能记录地址。接入地址需要公网 HTTPS，并验证实际来源公钥，禁重定向和 DNS 内网重绑定，不继承可信私网连接权限。

公共发现仅提供好友申请入口；经用户确认后直接联系来源服务器，产生待同意申请。对方接受以前不能读取私人记录或共享片单。不会通过公共节点转发好友凭据，也不把发现的服务器自动加入管理员可信连接。来源服务器仍需具备可访问的外部入口。

本机多实例路由与浏览器测试覆盖独立授权、陌生人发现、签名与有效期、撤回和重放、重新接入、本服投影与未接受好友的拒绝访问；真实互联网多服务器联调仍需另外一台已安装插件的服务器和自愿提供的公共入口。

## 高清片单封面与多图推荐

自建片单在「编辑片单 → 片单封面」中可从片单内影片选择 TMDB 剧照或海报，也可恢复自动组合。单图封面和宽封面按需加载高清图片，竖海报完整居中；编辑只保存私人片单，好友仍看到原先确认的共享快照，需另外更新分享。被排除作品的封面不会随过滤后的片单泄露。

推荐动态支持选择、移除和排序最多九张图片，点击图片可查看完整大图。1～3 张一行；4 张为 2×2；5、6 张为三列两行（五张的第二行两张）；7～9 张三列，最多三行。网格留白完整容纳原图，不裁切人物或海报文字。选择器显示完整画幅，并分批展示候选以避免大量图片同时加载。旧的单封面动态继续可用。

插件不再把详情图库另行截断为每类 24 张。主程序常规影视详情本身每类最多返回 20 张；管理员对有本服片源的影片可点「读取完整候选图库」，通过本人当前会话调用主程序现有的只读候选接口，展示其提供的全部 TMDB 候选，并沿用主程序的语言及图片来源规则。这不等于无条件取得 TMDB 全部语言的所有图片。没有本服条目或没有该接口权限时保持常规图库，并给出原因；不会读取宿主 TMDB 密钥、提升账号权限或修改主程序数据。所选图片只保存经过校验的 TMDB 相对文件名，不接受外部图床地址、路径或令牌。
