## 0.1.0

首次提交到 MovieClaw 插件仓库，安装 ID 为 `watch-friends`，显示名称为「映迹」。

- 原生 Web 页面、服务器账号头像与个人资料、跨来源观看足迹和电影／电视剧／单集统计。
- 私人片单与喜欢列表；高清可选片单封面，最多九张图片的推荐、评分、点赞、评论及举报。
- 按媒体库排除公开内容，可分别隐藏私人足迹和排除统计；公开预览与好友授权独立。
- 本人 Emby/Plex 导入，三平台已看对齐预览后确认同步；默认关闭的后台已看和续播同步，支持任务进度、暂停、停止与重试。
- 管理员双向批准的互联服务器、来源签名与短期名片、最多两次可信转发；独立默认关闭的可选公共发现，不内置公共入口。
- 统一宿主主题、图标、弹窗、折叠同步卡片和图片预览。插件只保存自己的数据，无需附加容器或端口。

跨服务器互联网联调尚待第二台真实服务器；本地多实例验证不等同于真实多服验收。续播为轮询式同步，不保证所有客户端即时无缝衔接。
