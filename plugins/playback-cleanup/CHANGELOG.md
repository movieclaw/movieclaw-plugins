# 续播进度清理

## 0.1.1 - 2026-11-05

- 支持无 TMDB / IMDb 编号的本地条目与「其他」视频库：没有外部编号的条目只凭条目 id + 类型写回
  （不再跳过成「无 TMDB/IMDb」）；读 catalog 时带 `kinds=movie,tv,video`，「其他」库的 `video` 条目也能清，
  按电影处理（单一 0/0 单元）；播放结束事件也接受 `video`。有编号的条目照旧带上吻合的编号。
- 需要宿主含 local-null sync 补丁（后续正式版）。在旧 0.46.0 上：catalog 不认 `kinds`，插件自动退回只看
  电影 / 剧集；对无编号条目的写回仍会回「身份不符」（mismatch），照实显示，不算清掉。
- 媒体库选择里「其他」视频库不再标成不建议。

## 0.1.0 - 2026-11-05

- 首个版本。在插件页面选一个媒体库和若干成员（含超管 0）：这些成员在这个库里**播放结束后**
  （`playback.stopped` / `playback.completed`），延迟一段时间（默认 45 秒，5–300 可调）再把那一集 / 那部片的
  续播进度清零。
- 只经 `playback.sync.state` 写 `position_ms = 0`，带 `expected_updated_at` 做 compare-and-set；
  冲突时重读一次、仍有进度就重试一次。不动已看、收藏、播放次数、音轨字幕、最近播放时间和播放流水。
- 可选每小时「兜底扫描」（默认开）：扫一遍选中库里选中成员残留的续播进度。
- 默认「只预览」：自动处理只记录会清什么；页面上的「立即清理一次」确认后真的写，不受这个开关影响。
- 没选媒体库或没选成员时什么都不做。
- 清理记录保存清理前的位置，可逐条撤销（之后又播过会冲突，撤销不了）；撤销过、之后没再动的单元，兜底扫描不会再清。
- 插件页面：概览 / 设置 / 清理记录。
