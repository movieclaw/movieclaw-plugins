配置助手 · 本站统计补充

补齐统计

如何获取个人统计样本？
  1. 在电脑 Chrome / Edge 登录自己的站点，打开自己的个人资料页，或包含个人上下传、积分、做种和下载数量的顶部账号栏。
  2. 右键目标区域 → 检查，在 Elements / 元素面板选择包含字段名称和数值的容器，右键 → Copy → Copy outerHTML。这里需要个人统计区块，无需种子列表或整个页面。
  3. 删除用户名、UID、邮箱、Cookie、密码以及链接内的 passkey、token 等密钥；保留标签、class / id、字段名称、数字和单位。请先自行检查，程序清理不能识别所有个人信息。
  4. 粘贴样本，勾选需要补齐的字段。可明确授权模型生成草稿，也可手动填写 CSS；点击预览检查每项数值，再保存规则并手动重新采集。预览数值仅来自样本，不会写入账号统计。

只补充当前站点个人统计的读取规则，不复制或覆盖整份官方适配。API 站点、登录失败及下载器问题需按原接口和连接方式处理。

本站自助接入

添加你的 PT 站点

已有适配直接添加；未收录站点可导入 YAML、使用标准模板，或由助手生成草稿。

1 · 先查支持目录

2 · 未收录站点，自行适配

已有适配文件可直接导入。没有文件？可先选择“标准模板”；需要按站点页面生成草稿时，选择“辅助适配”。

YAML 文件从哪里获取？如何导入？
  1. 从另一台已适配的服务器导出：在 PT岛“我的站点”展开对应的“本站自定义”站点，在“适配”区域点击“导出 YAML”，将下载的文件带到本服务器。
  2. 向适配维护者获取：请对方提供适用于 PT岛 / MovieClaw 的 NexusPHP 声明式 YAML，且域名与目标站点一致。目前此处没有独立的公共适配下载库；其他工具的同名 YAML 格式可能不同，不能保证直接导入。
  3. 载入文件：点击下方“选择文件”打开 .yaml / .yml 文件，或将配置原文粘贴到“适配配置”。这份文件描述页面字段和链接规则，不是种子文件，也不是 Cookie 或账号备份。
  4. 检查并使用：确认站点名称、ID 和域名后，点击“检查并加入本站目录”。再去“配置账号 / Cookie”保存自己的凭据，回到“我的站点”分别验证登录、搜索和详情。

没有现成文件无需自行寻找 Cookie 文件：切换到其他添加方式即可。导入成功仅代表配置格式通过检查，仍需实际验证。

没有 YAML、且站点采用常见 NexusPHP 页面时，可先生成模板；此方式不调用模型。

站点地址、ID 和名称怎么填？
  1. HTTPS 地址：从已登录站点的地址栏复制根地址，例如 https://example.com；不要带列表页路径、查询参数或登录密钥。
  2. 站点 ID 与名称：ID 是本服务器内唯一的简短标识：3–40 位，以小写字母开头，其余可用小写字母、数字、下划线或短横线，例如 examplept；显示名称填写站点常用名称。不要使用账号名或用户 ID。
  3. 生成并检查：点击“生成标准模板”，配置会出现在下方编辑框。模板提供常见列表、详情和分类规则；如果本站页面不同，需要修改对应选择器，或改用“辅助适配”提供页面样本。
  4. 加入并验证：点击“检查并加入本站目录”，再配置账号并验证登录、搜索和详情。模板不是已验证的完整适配；特殊 API 或非 NexusPHP 站点仍需要专用开发。

请提供自己有权访问的站点页面结构。列表页样本必填，详情页样本可选；截图、网址和 Cookie 不能替代 HTML 样本。

如何获取列表页和详情页 HTML？
  1. 打开真实列表：在电脑 Chrome / Edge 中登录自己的站点，进入有多条种子记录的列表页。不要复制首页、登录页或 Cloudflare 验证页。
  2. 找到列表区块：在一条种子记录上点击鼠标右键，选择“检查”。也可按 Mac ⌘⌥I，或 Windows Ctrl+Shift+I 打开开发者工具，在 Elements / 元素面板中向上选择包住多条种子记录的列表容器，确认页面高亮覆盖整个列表。
  3. 复制结构：在选中的 HTML 节点上点击右键，选择 Copy → Copy outerHTML（复制 → 复制 outerHTML）。将文本粘贴到下方“列表页 HTML”，保留种子标题、详情链接、大小、做种和下载等列；不要只复制某一行的标题文字。
  4. 补充详情（可选）：打开其中一个种子的详情页，用相同方式复制包含标题、大小、详情和下载入口的主体容器，粘贴到“详情页 HTML”。没有样本也可先生成，再通过真实详情验证补充适配。
  5. 先检查隐私：去除账号名、用户 ID、邮箱、个人流量等个人信息，以及 Cookie、密码、passkey、authkey、torrent_pass、API Key、token 等密钥。保留标签和 class / id 结构；链接中的密钥值替换为 REDACTED。不要复制 Network / 网络面板的请求头或浏览器 Cookie。尽量不选顶部账号栏和侧边个人信息；样本过大时缩小到所需区块。
  6. 生成与启用：检查样本后勾选模型授权，点击“生成适配草稿”。生成完成后点击“载入此任务草稿”，检查下方配置，再加入本站目录并配置账号验证。模型可能收费，草稿也可能需要修改；特殊框架或仅通过 API 加载的页面不保证能生成可用适配。

发送模型前程序会进一步清理样本，但不能保证识别全部个人信息，请先自行检查。不要为了提供样本上传整页账号资料或凭据。

填写地址与样本后，明确发起生成。

本地配置不会自动上传分享，最多保留十个历史版本。
