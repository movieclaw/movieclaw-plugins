# 更新记录

## 0.1.0

- 合并站点适配与辅助适配，提供管理员专用的 PT岛 页面。
- 统一管理官方、插件预置和本站自定义站点；未添加的站点留在支持库中。
- 支持 NexusPHP YAML 导入、标准模板、经用户同意的辅助适配、编辑、停用、归档及历史回退。
- 支持默认及单站浏览器 User-Agent，沿用原生账号、认证、代理和限流。
- 汇总个人上下传、分享率、积分与活动计数，提供逐字段采集检查及统计选择器补充向导。
- 读取下载器实时速度和分页任务明细；H&R 采用明确有考核、明确无考核和未知三态。
- 提供站点图标、柱状排行、环形占比、上传里程碑及本地 PNG 分享；隐私模式默认开启。
- 补读当前账号个人页的注册时间及已确认的账号 API 日期，自动计算已接入站点资历下限；取不到时支持自填参考。
- 注册日期证据加密保存并绑定账号与资料快照；可选采集失败不影响登录，已有日期保留。
- 补读海豹列表的精确发布时间，按站点时区转为 UTC，修复搜索正常但后台目录同步拒绝写入的问题。
- 修复辅助适配的模型确认框被文本输入框样式拉宽、说明挤成竖排的问题；统一确认控件尺寸与窄屏换行。
- 修复小屏横向任务弹窗无法滚动到列表和翻页按钮的问题；自定义长站名、域名及编辑提示在窄屏内换行。
- 数据、配置和内部标识沿用 `pt-site-pack`；版本保持 0.1.0。
