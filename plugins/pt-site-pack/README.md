# PT岛

版本固定 **0.1.0**。站点适配、本站目录和辅助适配合为一个管理员插件。

## 使用方式

主导航打开 `/apps/pt-site-pack`。默认“我的站点”只显示当前服务器已配置账号或手动添加的站点。各服务器配置独立；同一服务器沿用宿主共享的站点账号，不提供登录账号之间的 PT 数据隔离。

“添加站点”先搜索已有支持库：已支持的直接添加到本站，再去原生“资源站点”配置账号。未支持的选择：

1. **导入 YAML**：导入已有声明式适配，检查后加入本站目录。
2. **标准模板**：填写 HTTPS 域名、站点 ID、名称，生成 NexusPHP 模板，审核分类与选择器后加入。
3. **辅助适配**：提供脱敏的列表页、详情页样本，明确勾选模型调用后生成草稿。工具为 none，沿用宿主模型，可能产生费用。每次任务独立保存；失败任务不会返回上一次草稿。明确载入草稿后仍需审核。

三种方式均在页面提供可展开的获取步骤。YAML 可从另一台服务器的“我的站点 → 本站自定义站点 → 适配 → 导出 YAML”获得，或向维护者索取兼容 PT岛 / MovieClaw 的 NexusPHP 声明式配置；其他工具的 YAML 不保证通用，目前没有独立公共下载库。没有文件可先生成标准模板。辅助适配样本可在电脑 Chrome / Edge 的“检查 → Elements / 元素”中选择种子列表容器或详情主体，再通过“Copy → Copy outerHTML”复制；不要复制账号栏、网络请求头或 Cookie。粘贴前自行去除个人信息及链接中的密钥，程序清理不能代替人工检查。生成或导入后仍需配置自己的账号，分别验证登录、搜索与详情。

加入目录不代表账号已登录。Cookie 由宿主原生设置或浏览器扩展保存，插件不显示、导出或自行保存 Cookie。配置后分别验证登录、搜索与详情；页面诊断默认不获取种子文件，不提交下载任务。

本站自定义适配保存在当前服务器的插件持久数据与私有文件中，同版本更新及默认保留数据卸载后重装可恢复。支持编辑、停用、恢复上一版、归档及重新启用；最多保留 10 版配置历史。停用或归档不删除原生账号。导出文件只包含声明式适配，不携带 Cookie、密码或 User-Agent；分享由管理员主动操作，不自动上传。

当前自助范围为 **NexusPHP + Cookie**；特殊 API / 其他框架需要专用适配器。导入拒绝代码、custom_class、登录表单、凭据、私有 IP、冲突 ID 或域名；已有自定义 ID 不能改绑到其他域名。辅助草稿和模板都需要真实站点验证。

## 数据总览与分享

新增“数据总览”页签，仍只显示当前服务器已添加的官方、插件和本站自定义站点。累计上传/下载、分享率、魔力与站点做种/下载数量来自原生账号缓存；实时速度、任务数量和种子明细来自只读 `dl.tasks`。重复任务按下载器与 infohash 去重；无可信站点来源的任务单独归类。顶部速度包括未归属任务，各站速度只计算已关联任务。

账号验证时，插件对官方、预置和本站自定义适配统一补读已请求的个人资料页与登录导航，注册时间缺失的 NexusPHP 在资料采集时最多补读一次当前账号的 `userdetails.php?id=…`，沿用宿主客户端并设置 15 秒上限；普通登录探测不会增加此请求。支持嵌套元素、相邻文本、合并传输行、改版顶栏及图标/文字标注计数，保留原认证、限流、代理和专用 API 解析。海豹另外通过 Gazelle 的 `ajax.php?action=user` 读取当前账号的个人活动计数，只保留白名单数字，不读取凭据字段；请求仍走宿主认证与限流。普通登录探测不覆盖已有资料证据。

仅当资料页 UID 或用户名标题匹配当前账号时才补读资料表格，防止裸地址返回首页/FAQ 后，把全站做种总数填入个人统计。观众读取可用爆米花而非做种积分，猫站读取猫粮，织梦读取电力值；同一页面上的其他积分、银行或兑换价不混入主积分。自定义导入支持宿主原有的 `::next_sibling_text` 选择器。

缺少站点分享率但上下传完整且下载量大于零时显示“计算值”。每站提供“补齐资料 / 更新资料”，明确触发原生账号验证与采集，同站至少间隔 60 秒；普通刷新只读缓存与下载器。

每张站点卡片提供“统计检查”，在有界弹窗逐项列出六项个人统计、注册资历、五项下载器实时字段及 H&R 任务标记覆盖。显示数值、来源、资料时间、已采集 / 计算值 / 未识别 / 待采集 / 请求失败 / 暂不可用 / 部分可用等状态；保留旧值时同时显示最近账号验证状态。无关联任务不视为 H&R 已检查，下载器任务数不等于全站个人做种数。检查只读取已有快照，不自动访问站点或调用模型。

登录验证正常的 HTML 站点可从缺失项进入“配置助手 · 补齐统计”，提供脱敏的个人资料页或账号栏 outerHTML，选择缺失字段。支持手工填写 CSS，也可明确授权本服务器模型生成草稿，可能产生费用。逐项样本预览只验证规则能否解析数值，不作为真实账号统计；新增 / 修改的非空规则须在样本中成功解析才可保存，模型结果不自动应用。保存后返回数据总览手动重新采集验证。仅覆盖当前站点的六项个人统计读取，原账号、登录、搜索与下载规则保留；规则独立持久保存，最多保留十版，可恢复上一版或清空以沿用原适配。

当前统计补充向导支持 NexusPHP / Gazelle 已请求的 HTML 页面，不接受任意资料地址。API 或特殊框架提示交由维护者补充接口解析；账号验证失败、代理 / Cloudflare、下载器连接与任务归属不通过 HTML 选择器解决。隐私切换会清除旧检查内容和样本；隐藏站点时禁止进入会显示真实站名的补齐向导。HTML 样本不保存，发送模型前进一步清理，但用户仍需先删除个人信息与密钥。原自助添加流程继续保留，插件版本仍为 0.1.0。

旧宿主解析器可能把未采集字段填为 0。插件以实际解析证据区分真实零和未知；M-Team、朱雀使用已请求的成功账号/活动接口确认字段存在，不把接口失败或缺键当成零。证据只存白名单数字与来源，绑定同账号、同次资料快照，不存页面、账号名或认证信息。旧快照缺证据时，双零累计量且无分享率、双零活动计数继续显示未知。字段仍未识别时不猜测，不保证特殊框架全字段自动可用；自定义 NexusPHP 可通过资料选择器补充。显示数据时间与过期状态，读取失败保留旧快照并标注。没有下载器时实时字段为未知，不显示零带宽。

任务弹窗默认每页 20 条，支持站点、名称、状态和 H&R 筛选。手机端全屏呈现；桌面端限定高度并内部滚动，不把所有任务堆在主页面。

H&R 使用有考核 / 明确无考核 / 未知三态。自然搜索、列表和详情中可补读明确 API 布尔标记或逐种 HTML 标记；“选择器没命中图标”不再当作无考核，旧缓存中缺少明确来源的否定结果也不采用。证据按站点与种子 ID 关联，最多保留 256 条、有效期 7 天，不读取宿主数据库。

有可信站点和详情地址的任务可手动“核对 H&R”，通过一次性票据读取该种子详情，不实际搜索、不记录搜索历史、不下载种子或新增任务。同站至少间隔 60 秒，仅允许该站 HTTPS 详情地址，剥离无关查询参数；任务顺序变化不会把核对请求绑定到其他任务。缺少站点来源、地址、账号验证或明确标记时保留未知并说明原因。H&R 证据不代表个人考核已完成，不推算已达标、违规或剩余时间；此版本不提供站端全量个人做种列表或精确 H&R 倒计时。

隐私模式默认开启：服务端响应即移除账号及下载器名称；可额外隐藏站点和种子名称。切换后清除旧内容再加载，不用模糊遮罩保留可见原文。

分享图在浏览器本地生成，可预览后下载 PNG；默认隐私分享，另有完整展示。支持当前筛选站点、单站或当前任务页，超过 24 站自动分图。图片累计量及速度只汇总所选站点，未归属任务不计入。所有模式均不输出 Cookie、密钥、路径、infohash 或下载链接，不自动上传；完整展示按用户选择包含可见账号/任务资料。

分享 PNG 绘制同源缓存的站点图标，等待图片加载后才允许下载；读取失败使用文字头像，不中断导出。任务分享也按可信站点关联绘制图标。隐藏站点时，同时移除真实名称和图标，使用匿名站点及通用头像，不能靠图标识别站点。站点分享卡片另显示大致注册时长及上传里程碑，不输出具体注册日期。

总览新增可折叠的“图表与岛民名片”：柱状排行最多显示前八站，环形占比最多五站加“其他”；支持累计上传、累计下载、站点做种和实时上传速度，随当前名称筛选、来源及快照更新。缺失字段不按零计入分母，全零不虚构占比；点击排行或图例可打开该站采集检查。使用原生 SVG 和宿主主题，不引入外部图表依赖；动画尊重系统减少动态效果设置，不伪造历史趋势。

“P 龄参考”优先使用当前筛选站点中最早的有效注册记录，并展示采集覆盖数。这是可证明的资历下限，不代表全部 PT 经历。只认当前账号个人页中明确的注册 / 加入日期，以及已确认的账号 API 日期；支持表格、资料卡、精确日期属性，不按“几年前”文字倒推。UID、账号名或成功接口身份不匹配的记录不采用；不使用站点创建时间、种子发布时间、上传量、等级或服务器接入时间。

宿主对外资料接口未返回注册日期时，插件使用同次账号采集产生的加密日期证据；证据绑定账号及资料快照，不保存原始页面。可选资料页请求失败不影响原账号验证，也不清除同账号已验证的日期。不同账号不会继承旧日期。手动“更新资料”可补采，普通页面刷新不请求 PT 站。

当前筛选站点全部没有日期时，才采用自填首次入圈日期，明确标注未经验证。自填默认只在本次页面有效，勾选后仅保存在当前浏览器当前服务器地址的本地存储；可清除，已有自填记录仍保留作缺失时的后备。隐私响应移除具体注册日期字段，分享图只显示大致时长和来源。

上传里程碑按当前筛选站点的累计上传计费量展示“资源旅人 / 做种领航员 / 群岛守望者”等称号和下一档进度，仅供娱乐。站点促销和重复跨站上传会影响累计量，不当作真实带宽、个人能力或全网排名。所有新增展示均沿用现有数据与权限，版本继续固定 0.1.0。

新增权限仅 `dl.tasks`，没有投递、暂停或删除任务的权限。原有配置、账号和私有数据沿用，版本仍为 0.1.0。

## 浏览器身份与迁移

“浏览器身份设置”提供默认 User-Agent；每个站点详情提供单站覆盖，留空继承默认，默认也留空则沿用宿主客户端设置。覆盖只改变请求头，保留原有 Cookie、API 认证、代理、限流与重试。当前官方库、插件库以及本站自定义 NexusPHP 站点使用同一机制。

旧的百川 User-Agent 自动迁入单站覆盖。旧配置原值保留用于回退；旧的管理地址、固定六站开关、Agent 请求编号等不再显示。既有停用状态继续沿用。助手旧草稿可迁入任务历史，旧编号不会自动触发模型。独立旧助手命名空间保留，不跨插件读取凭据。

UA 一致不能保证通过 Cloudflare；需要有效会话与一致出口。旧宿主的 JSON Cookie 解析问题需由宿主修复；插件不会自动修改服务器源码，也不能保证通过人机验证。

## 安装与开发

原生导航只对管理员显示，不开放 web-members。旧 `/api/v1/plugins/pt-site-pack/panel` 链接兼容，但设置页不再重复展示管理地址。

```sh
python plugins/pt-site-pack/tools/build_web.py
mclaw plugin pack plugins/pt-site-pack --output-file pt-site-pack-0.1.0.mcplugin
mclaw app plugins packages upload --file pt-site-pack-0.1.0.mcplugin
mclaw app plugins packages approve pt-site-pack --version 0.1.0 --operations-json '["site.catalog","site.list","site.stats","site.verify","search.torrents","dl.tasks","agent:none"]' --paths-json '[]' --allow-inline --allow-web --web-nav --yes
```

宿主不接受覆盖安装相同版本。先备份旧包，再卸载（不带 purge-data）、上传并批准；失败则恢复旧包。插件 inline 与主程序同权限，需要管理员审阅，宿主权限范围不增加。插件不修改主程序文件。

```sh
PYTHONPATH=/path/to/MovieClaw/src:plugins/pt-site-pack python -m unittest discover -s plugins/pt-site-pack/tests -t plugins/pt-site-pack -v
node --test plugins/pt-site-pack/tests/test_insights.cjs
```

测试包含真实目录注册与重载、模拟账号验证/搜索/详情、全站 UA、编辑回退归档、导入与模型限制、并发版本冲突、持久化失败恢复及不同服务器独立。模拟网络夹具不使用生产账号。

品牌沿用深青绿底、奶油金主体与薄荷绿点缀的桥形图标。站点图标使用包内缓存，无图标时安静回退文字头像，不发送站点清单给第三方服务。
