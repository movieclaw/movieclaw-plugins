# 企业微信直推

通过企业微信自建应用发送影视通知，支持中文 Jinja2 模板、海报图文、文本卡片，以及网盘上传成功文件名。插件 ID 为 `notifyhub`，用于保留早期版本用户的设置和去重数据；无需部署 NotifyHub。

## 功能

- 新建订阅、开始下载、下载完成、整理入库、媒体库新增和洗版提醒。
- 文件入账后默认合并 5 秒再处理，同一部剧的新增集数合并显示；持续入账最多等 15 秒开始处理。
- 新建库首次扫描、大批量扫描保留原生汇总兜底，快速通知和原生通知共享去重。
- 上传任务成功后显示媒体库名、成功/秒传数量、确认成功的文件名；部分失败明确标注。
- 可选播放提醒、系统 IM 通道告警；电影隐藏季集，缺失字段自动隐藏。
- 分片去重存储，每值最多 32 KiB，避免超过宿主 64 KB 上限后反复投递。

## 安装与配置

从插件管理上传发布包并批准清单权限，填写 CorpID、AgentID、应用 Secret 和接收成员 UserID。多个成员用 `|` 分隔；只有希望向应用可见范围内全部成员发送时填写 `@all`。后台应配置可信出口 IP，并确认接收成员在应用可见范围内。未填写完整凭据时插件正常加载但不发送。

旧版用户直接覆盖升级，保留 `notifyhub` ID，不要先卸载。新增权限需重新批准。自定义模板保持不变；精确匹配旧默认文本的模板自动采用新默认设计。

“MovieClaw 访问地址”统一用于详情跳转和图片，例如 `https://media.example.com`，只填写根地址。图片使用 MovieClaw 的 Jellyfin 兼容接口，需要兼容服务开启且企业微信可以匿名访问图片。没有缓存且服务器无法回源时仍可能无图；不会上传图片素材或附带登录令牌。

## 通知来源和去重

订阅、下载、入库与媒体库新增使用原生可靠事件，不需要发往 NotifyHub 的 Webhook。相同作品/季集的整理入库、订阅完成和媒体库新增默认在 35 分钟内合并；洗版单独提醒。事件 ID 去重保留 7 天，容量有限时淘汰旧记录。

快速新增跳过新建库头 24 小时的扫描文件、已有更早版本的同一电影/剧集、未识别内容、图片库和缺失文件。单批超过 200 个文件或 20 部作品、或者读取详情接口不可用时，保留原生汇总通知，可能延迟数分钟。公开详情没有文件原始修改时间，给既有库加入少量旧文件仍可能被快速通道视为新增。

网络、服务查询和发送会增加处理时间，不保证所有通知 5 秒内送达。发送成功后进程崩溃或网络超时等情况仍可能重复，不能提供严格一次投递。

## 网盘上传完成

默认每 30 秒通过只读 `jobs.list` 查询 `drive.upload` 最终结果，再读 `jobs.events` 时间线，以文件名和成功计数共同确认成功文件。仅运行结束且成功数大于 0 时通知；部分失败标为“部分完成”，失败文件不列入成功清单。

默认纯文本，按消息长度预算最多列出 20 个文件，标明未展开或无法确认名称的数量。上传正文支持 `filenames`、`filenames_remaining`、`filenames_missing`、`uploaded`、`rapid`、`failed` 等变量，见 [模板说明](TEMPLATES.md)。任务完成不代表本地文件全部腾空。

首次启用不补发历史任务。每次最多读取最近创建的 200 个成功任务；长期停机、任务记录清理或极端任务量可能使早期任务无法补查。任务时间线读取失败时延后重试。

## 播放与系统告警

播放需开启插件开关，并在管理员登录后访问 `/api/v1/plugins/notifyhub/integration` 获取回调 URL。MovieClaw 内置 Webhook 选择原生 `type/id/data` 格式，只选择需要的 `playback.started`、`playback.completed`、`playback.stopped`。回调 URL 含密钥，不要公开。忽略进度事件；停止时已看完不再重复提醒。

告警绑定插件提供的企业微信 IM 通道，建议只勾选系统告警，避免与原生业务事件形成第二路推送。

## 开发与验证

插件随包提供纯 Python Jinja2/MarkupSafe，保留其许可证，不在安装时执行脚本或 pip。

在已安装 MovieClaw 的 Python 环境中，仓库 CI 使用标准库测试：

```sh
python -m unittest discover -s plugins/notifyhub/tests -t plugins/notifyhub -v
```

完整回归套件在 `qa/`，开发环境另装 `pytest` 和 `pytest-asyncio` 后运行：

```sh
PYTHONPATH=plugins/notifyhub:plugins/notifyhub/vendor python -m pytest plugins/notifyhub/qa -q
```

完整套件包含真实 SDK 子进程和本地模拟企业微信/宿主接口，并不是线上企业微信或网盘实测。尚未验证各用户实际容器、公开图片、企业微信可信 IP/可见范围或手机客户端外观。

源码测试使用的 SDK 基线和验证边界见 [验证报告](VERIFICATION.md)。第三方库许可证见 `vendor/*dist-info/licenses/`。
